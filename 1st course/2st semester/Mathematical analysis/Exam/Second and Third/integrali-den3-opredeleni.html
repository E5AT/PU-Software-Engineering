Блок 01
Какво е определен интеграл?
⏱ ~20 мин
💡 Разликата от неопределения

НЕОПРЕДЕЛЕН

∫ f(x) dx = F(x) + C

Резултатът е функция.
Няма граници на интегриране.
Задължително + C.

ОПРЕДЕЛЕН

∫ₐᵇ f(x) dx = число

Резултатът е число.
Има долна (a) и горна (b) граница.
Без + C!

📐 Геометричният смисъл
Защо изобщо съществува определеният интеграл
!
∫ₐᵇ f(x) dx = лице под кривата
Определеният интеграл пресмята лицето на фигурата между кривата y=f(x), x-оста и правите x=a и x=b.

• Ако f(x) > 0 → интегралът е положителен (фигура над x-оста)
• Ако f(x) < 0 → интегралът е отрицателен (фигура под x-оста)
• Ако искаш реалното лице → вземаш |интеграл|
💡 На изпита рядко питат за геометричния смисъл — но помага да разбереш защо смяната на граници при смяна на променлива е задължителна!
Блок 02
Формула на Нютон-Лайбниц
Как реално се пресмята определен интеграл
⏱ ~25 мин
📋 Формулата
∫ₐᵇ f(x) dx = F(b) − F(a) = [F(x)]ₐᵇ
💡 С думи: Намираш първообразната F(x) (без + C!), после заместваш горната граница b и изваждаш стойността при долната граница a.
⚠️ Без + C! При определен интеграл константата C се съкращава (F(b)+C − F(a)−C = F(b)−F(a)), затова не я пишем.
⚙️ Алгоритъм

⚡ Как пресмяташ определен интеграл

1
Намери първообразната F(x) — точно като неопределен интеграл, но без + C
2
Запиши в скоби с граници: [F(x)]ₐᵇ
3
Замести горната граница b: намери F(b)
4
Замести долната граница a: намери F(a)
5
Изчисли F(b) − F(a) — това е отговорът (число!)
📘 Примери
Ex1
∫₀² x² dx
Първообразна: F(x) = x³/3
[x³/3]₀² = (2³/3) − (0³/3) = 8/3 − 0
= 8/3
Ex2
∫₀^π sin x dx
Първообразна: F(x) = −cos x
[−cos x]₀^π = (−cos π) − (−cos 0) = 1 − (−1) = 2
= 2
Ex3
∫₁^e (1/x) dx
Първообразна: F(x) = ln|x|
[ln x]₁^e = ln(e) − ln(1) = 1 − 0
= 1
Ex4
∫₀¹ (3x² + 2x − 1) dx
Първообразна: F(x) = x³ + x² − x
F(1) = 1 + 1 − 1 = 1
F(0) = 0 + 0 − 0 = 0
= 1 − 0 = 1
Ex5
∫₀¹ eˣ dx
Първообразна: F(x) = eˣ
[eˣ]₀¹ = e¹ − e⁰ = e − 1
= e − 1 ≈ 1.718
Блок 03
Свойства на определения интеграл
⏱ ~20 мин
📋 Основни свойства
1
Линейност
∫ₐᵇ [f±g] dx = ∫ₐᵇf dx ± ∫ₐᵇg dx
Разбиваш на сбор/разлика
2
Константа
∫ₐᵇ k·f dx = k · ∫ₐᵇ f dx
Константата излиза пред
3
Обръщане на граници
∫ₐᵇ f dx = − ∫ᵦᵃ f dx
Смяната на граници обръща знака
4
Равни граници
∫ₐᵃ f dx = 0
Интеграл от a до a = 0
5
Адитивност
∫ₐᵇ f dx = ∫ₐᶜ f dx + ∫ᶜᵇ f dx
Разбиваш на два интеграла в точка c
6
Четна/Нечетна
f четна: ∫₋ₐᵃ = 2∫₀ᵃ f dx f нечетна: ∫₋ₐᵃ = 0
При симетрични граници [−a, a]
💡 Свойство 6 е особено полезно! Ако имаш ∫₋₂² x³ dx — x³ е нечетна функция → интегралът = 0 директно, без изчисления!
📘 Примери за свойствата
Ex1
∫₋₃³ x⁵ dx = ?
x⁵ е нечетна функция (f(−x) = −f(x))
Границите са симетрични [−3, 3]
По свойство 6: = 0 (без изчисления!)
Ex2
∫₋₂² x² dx = ?
x² е четна функция, граници [−2, 2]
По свойство 6: = 2∫₀² x² dx = 2[x³/3]₀²
= 2·(8/3) = 16/3
= 16/3
Ex3
Адитивност: ∫₀³ f dx = ∫₀¹ f dx + ∫₁³ f dx
Ако знаеш ∫₀¹ f dx = 2 и ∫₁³ f dx = 5, тогава:
∫₀³ f dx = 2 + 5 = 7
Блок 04
Смяна на граници при смяна на променлива
Най-важната разлика от неопределения интеграл!
⏱ ~30 мин
⚠️ Задължителна смяна на граници!
Когато правиш смяна t = g(x) в определен интеграл
⚠️ Много важно: При смяна на променлива t = g(x) в ОПРЕДЕЛЕН интеграл ТРЯБВА да смениш и границите! Не можеш да работиш с граници за x и функция от t!
Ако t = g(x): новата долна граница = g(a), новата горна граница = g(b)
⚙️ Алгоритъм

⚡ Смяна на променлива в определен интеграл

1
Избери t = g(x) — същото като при неопределен интеграл
2
Намери dt = g'(x)dx
3
Смени границите: долна: t = g(a), горна: t = g(b)
4
Реши интеграла по t с новите граници — вече не се връщаш към x!
5
Приложи Нютон-Лайбниц с новите граници за t
📘 Примери
Ex1
∫₀¹ 2x·e^(x²) dx
t = x² → dt = 2x dx
Смяна на граници:
• x=0: t = 0² = 0
• x=1: t = 1² = 1
Новият интеграл: ∫₀¹ eᵗ dt
= [eᵗ]₀¹ = e¹ − e⁰ = e − 1
= e − 1
Ex2
∫₀^(π/2) sin x · cos²x dx
t = cos x → dt = −sin x dx → sin x dx = −dt
Смяна на граници:
• x=0: t = cos 0 = 1
• x=π/2: t = cos(π/2) = 0
Новият интеграл: ∫₁⁰ t²·(−dt) = ∫₀¹ t² dt
= [t³/3]₀¹ = 1/3 − 0
= 1/3
Ex3
∫₁⁴ x/√(x²+9) dx
t = x²+9 → dt = 2x dx → x dx = dt/2
Смяна на граници:
• x=1: t = 1+9 = 10
• x=4: t = 16+9 = 25
Новият интеграл: ∫₁₀²⁵ (1/√t)·(dt/2) = (1/2)∫₁₀²⁵ t^(-1/2) dt
= (1/2)[2√t]₁₀²⁵ = [√t]₁₀²⁵ = √25 − √10 = 5 − √10
= 5 − √10
Блок 05
Задачи за практика
⏱ ~60 мин
🟢 Лесни — Директно Нютон-Лайбниц
ЗАДАЧА 01
∫₁³ (2x + 1) dx
👆 Кликни за решение
Първообразна: x² + x
[x²+x]₁³ = (9+3) − (1+1) = 12 − 2
= 10
ЗАДАЧА 02
∫₀^(π/2) cos x dx
👆 Кликни за решение
Първообразна: sin x
[sin x]₀^(π/2) = sin(π/2) − sin(0) = 1 − 0
= 1
ЗАДАЧА 03
∫₁^e ln(x)/x dx
💡 Смяна t = ln x, dt = (1/x)dx
👆 Кликни за решение
t = ln x → dt = (1/x)dx
Граници: x=1 → t=0; x=e → t=1
∫₀¹ t dt = [t²/2]₀¹ = 1/2
= 1/2
ЗАДАЧА 04
∫₋₂² (x³ + x) dx
💡 Провери за четност/нечетност!
👆 Кликни за решение
x³ е нечетна, x е нечетна → x³+x е нечетна
Границите са симетрични [−2, 2]
По свойство 6 за нечетни функции:
= 0
ЗАДАЧА 05
∫₀¹ x·eˣ dx
💡 Интегриране по части! u=x, dv=eˣdx
👆 Кликни за решение
По части: u=x, dv=eˣdx → du=dx, v=eˣ
∫₀¹ xeˣdx = [xeˣ]₀¹ − ∫₀¹ eˣdx
= (1·e − 0) − [eˣ]₀¹
= e − (e − 1)
= 1
🟡 Средни — Смяна на граници
ЗАДАЧА 06
∫₀¹ x·(x²+1)³ dx
💡 t = x²+1, смени и границите!
👆 Кликни за решение
t=x²+1 → dt=2x dx → x dx=dt/2
Граници: x=0→t=1; x=1→t=2
∫₁² t³·(dt/2) = (1/2)[t⁴/4]₁² = (1/8)(16−1)
= 15/8
ЗАДАЧА 07
∫₀^(π/4) sin(2x) dx
💡 Константа под d: a=2
👆 Кликни за решение
Константа под d, a=2:
Първообразна: −(1/2)cos(2x)
[−(1/2)cos(2x)]₀^(π/4)
= −(1/2)cos(π/2) − (−(1/2)cos(0))
= 0 + 1/2
= 1/2
ЗАДАЧА 08
∫₀¹ eˣ/(eˣ+2) dx
💡 t = eˣ+2, производната е eˣ!
👆 Кликни за решение
t=eˣ+2 → dt=eˣdx
Граници: x=0→t=e⁰+2=3; x=1→t=e+2
∫₃^(e+2) (1/t)dt = [ln t]₃^(e+2)
= ln(e+2) − ln 3
= ln((e+2)/3)
ЗАДАЧА 09
∫₀¹ x·ln(x+1) dx
💡 Интегриране по части: u=ln(x+1), dv=x dx
👆 Кликни за решение
u=ln(x+1), dv=x dx → du=1/(x+1)dx, v=x²/2
= [x²/2·ln(x+1)]₀¹ − ∫₀¹ x²/(2(x+1)) dx
= (1/2)ln2 − 0 − (1/2)∫₀¹ x²/(x+1) dx
За ∫x²/(x+1)dx: x²/(x+1) = x−1+1/(x+1)
∫₀¹(x−1+1/(x+1))dx = [x²/2−x+ln(x+1)]₀¹
= (1/2−1+ln2) − 0 = ln2 − 1/2
= (1/2)ln2 − (1/2)(ln2−1/2)
= (1/2)ln2 − (1/2)ln2 + 1/4 = 1/4
ЗАДАЧА 10 — Свойства
∫₋π^π (x⁴·cos x + x·sin²x) dx
💡 Анализирай четността на всеки член!
👆 Кликни за решение
Граници: симетрични [−π, π]

x⁴·cos x: x⁴ е четна, cos x е четна → произведението е четна
∫₋π^π x⁴cos x dx = 2∫₀^π x⁴cos x dx (нужно по части — не пресмятаме)

x·sin²x: x е нечетна, sin²x е четна → произведението е нечетна
∫₋π^π x·sin²x dx = 0

Забележка: ако задачата иска само да покажеш свойствата → вторият член = 0 директно!
