Блок 01
Какво е неопределен интеграл?
Интуицията преди формулите
⏱ ~20 мин
💡 Основната идея
Интегрирането е обратното на диференцирането
?
Аналогията
Знаеш че (x²)' = 2x

Неопределеният интеграл пита обратното:
"Коя функция, като я диференцираме, дава 2x?"

Отговорът е x² — но и x²+1, x²+5, x²+C за всяка константа C!
Затова пишем: ∫ 2x dx = x² + C
!
Константата C — задължителна!
Винаги добавяш + C в края.
C е произволна константа — не можем да знаем точната стойност без допълнително условие.

Без + C → грешен отговор на изпит!
∫ f(x) dx = F(x) + C    където F'(x) = f(x)
💡 Терминология: f(x) се казва подинтегрална функция, dx показва спрямо коя променлива интегрираме, F(x) е първообразна на f(x).
✅ Как проверяваш резултата
Диференцирай отговора — трябва да получиш подинтегралната функция
Ex
Твърдим: ∫ 3x² dx = x³ + C

Проверка: (x³ + C)' = 3x² + 0 = 3x² ✓

Получихме обратно подинтегралната функция → правилно!
💡 Навик за изпит: Винаги можеш да проверяваш сам като диференцираш отговора. Ако получиш подинтегралната функция — правилно!
Блок 02
Свойства на неопределения интеграл
⏱ ~20 мин
Четирите основни свойства
1. ∫ [f(x) + g(x)] dx = ∫ f(x) dx + ∫ g(x) dx
2. ∫ [f(x) − g(x)] dx = ∫ f(x) dx − ∫ g(x) dx
3. ∫ k·f(x) dx = k · ∫ f(x) dx    (k = константа ≠ 0)
4. [∫ f(x) dx]' = f(x)    (интеграл и производна се "унищожават")
⚠️ Важно за свойство 3: Константата излиза пред интеграла. Но ако имаш функция от x — НЕ можеш да я изнесеш!
✓ ∫ 5x² dx = 5∫ x² dx
✗ ∫ x·sin(x) dx ≠ x · ∫ sin(x) dx
Примери за прилагане на свойствата
Ex1
∫ (3x² + 2x − 5) dx
Свойство 1 (разбиваш): ∫3x²dx + ∫2x dx − ∫5 dx
Свойство 3 (изнасяш): 3∫x²dx + 2∫x dx − 5∫dx
По таблицата: 3·(x³/3) + 2·(x²/2) − 5x + C
= x³ + x² − 5x + C
Ex2
∫ (eˣ − cos x + 1/x) dx
= ∫eˣdx − ∫cos x dx + ∫(1/x)dx
= eˣ − sin x + ln|x| + C

Блок 04
Алгоритъм за непосредствено интегриране
Следвай стъпките преди да пишеш нещо
⏱ ~15 мин

⚡ Алгоритъм — Непосредствено интегриране

1
Опрости израза — разкрий скоби, раздели дроби, запиши корени като степени (√x = x^(1/2))
2
Разбий на сбор/разлика — използвай свойство 1 и 2 за да разбиеш на по-прости интеграли
3
Изнеси константите — използвай свойство 3 за числата пред функциите
4
Намери интеграла по таблицата — всеки член трябва да съответства на табличен интеграл
5
Добави + C — задължително! Само един C в края, не за всеки член.
6
Провери — диференцирай резултата, трябва да получиш f(x)
Пример — Пълно решение по алгоритъма
Ex
∫ (2x³ − 3√x + 5/x − eˣ) dx
Стъпка 1 — Запиши корена като степен:
∫ (2x³ − 3x^(1/2) + 5·x⁻¹ − eˣ) dx

Стъпки 2-3 — Разбий и изнеси:
= 2∫x³dx − 3∫x^(1/2)dx + 5∫(1/x)dx − ∫eˣdx

Стъпка 4 — По таблицата:
= 2·(x⁴/4) − 3·(x^(3/2)/(3/2)) + 5·ln|x| − eˣ
= (x⁴/2) − 3·(2/3)·x^(3/2) + 5ln|x| − eˣ

Стъпка 5 — + C:
= x⁴/2 − 2x^(3/2) + 5ln|x| − eˣ + C
Блок 05
Задачи за практика
Кликни за решение — но първо опитай сам!
⏱ ~40 мин
🟢 Лесни — Директно от таблицата
ЗАДАЧА 01
∫ x⁵ dx
👆 Кликни за решение
= x⁶/6 + C
Формула xⁿ: степента нараства с 1, делиш на новата степен
ЗАДАЧА 02
∫ (1/x³) dx = ∫ x⁻³ dx
👆 Кликни за решение
∫ x⁻³ dx = x⁻²/(−2) + C
= −1/(2x²) + C
ЗАДАЧА 03
∫ (eˣ + cos x) dx
👆 Кликни за решение
= eˣ + sin x + C
ЗАДАЧА 04
∫ (3/x + 2sin x) dx
👆 Кликни за решение
= 3∫(1/x)dx + 2∫sin x dx
= 3ln|x| − 2cos x + C
🟡 Средни — Опростяване преди интегриране
ЗАДАЧА 05
∫ (x + 1)² dx
💡 Разкрий скобата първо!
👆 Кликни за решение
Разкриваме: (x+1)² = x² + 2x + 1
∫(x²+2x+1)dx = x³/3 + x² + x + C
= x³/3 + x² + x + C
ЗАДАЧА 06
∫ (x² + 3x − 2) / x dx
💡 Раздели дробта на x
👆 Кликни за решение
Разделяме: x²/x + 3x/x − 2/x = x + 3 − 2/x
∫(x + 3 − 2/x)dx
= x²/2 + 3x − 2ln|x| + C
ЗАДАЧА 07
∫ (√x + 1/√x) dx
💡 Запиши като степени: x^(1/2) и x^(-1/2)
👆 Кликни за решение
∫(x^(1/2) + x^(-1/2))dx
= x^(3/2)/(3/2) + x^(1/2)/(1/2) + C
= (2/3)x^(3/2) + 2√x + C
ЗАДАЧА 08
∫ (x³ − 1) / x² dx
💡 Раздели на x²
👆 Кликни за решение
x³/x² − 1/x² = x − x⁻²
∫(x − x⁻²)dx = x²/2 − x⁻¹/(−1) + C
= x²/2 + 1/x + C
ЗАДАЧА 09
∫ (2x − 1)(x + 3) dx
💡 Разкрий произведението
👆 Кликни за решение
(2x−1)(x+3) = 2x²+6x−x−3 = 2x²+5x−3
∫(2x²+5x−3)dx
= (2/3)x³ + (5/2)x² − 3x + C
ЗАДАЧА 10
∫ (5·2ˣ − 3/cos²x + 2/√(1−x²)) dx
💡 Три члена — три табл. формули
👆 Кликни за решение
= 5∫2ˣdx − 3∫(1/cos²x)dx + 2∫(1/√(1−x²))dx
= 5·(2ˣ/ln2) − 3tg(x) + 2arcsin(x) + C
