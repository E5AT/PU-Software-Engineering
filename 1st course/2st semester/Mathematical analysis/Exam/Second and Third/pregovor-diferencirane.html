Блок 02
Правила за диференциране
⏱ ~20 мин
Четирите правила
КОНСТАНТА × ФУНКЦИЯ
(c·f)' = c·f'
Пример: (5x³)' = 15x²
СУМА / РАЗЛИКА
(f ± g)' = f' ± g'
Пример: (x²+sinx)' = 2x+cosx
ПРОИЗВЕДЕНИЕ
(f·g)' = f'g + fg'
Пример: (x·eˣ)' = eˣ + xeˣ
ЧАСТНО
(f/g)' = (f'g − fg')/g²
Пример: (sinx/x)' = (xcosx−sinx)/x²
⚠️ Честа грешка при частното: ВИНАГИ е f'g − fg' (не обратното!). Знаменателят е g², не g!
Примери
1
f(x) = 4x⁵ − 3x³ + 7x − 2
f'(x) = 20x⁴ − 9x² + 7
2
f(x) = x² · cos(x)
Произведение: f'(x) = 2x·cosx + x²·(−sinx) = 2xcosx − x²sinx
3
f(x) = eˣ / (x² + 1)
Частно: f'(x) = [eˣ(x²+1) − eˣ·2x] / (x²+1)²
= eˣ(x²−2x+1)/(x²+1)² = eˣ(x−1)²/(x²+1)²
4
f(x) = x · ln(x) − x
Произведение + разлика:
f'(x) = 1·ln(x) + x·(1/x) − 1 = lnx + 1 − 1 = ln(x)
Блок 03
Верижно правило
За сложни (композирани) функции
⏱ ~20 мин
Формулата
[f(g(x))]' = f'(g(x)) · g'(x)
💡 С думи: "Производна на външната (оставяш вътрешната) × производна на вътрешната"
⚠️ Най-честата грешка: Забравяш да умножиш по производната на вътрешната функция!
Примери — бързо
1
f(x) = e^(3x²+1)
Външна: eˣ, вътрешна: 3x²+1
f'(x) = e^(3x²+1) · 6x
2
f(x) = sin(x³)
Външна: sin, вътрешна: x³
f'(x) = cos(x³) · 3x²
3
f(x) = ln(x²+5)
Външна: ln, вътрешна: x²+5
f'(x) = 1/(x²+5) · 2x = 2x/(x²+5)
4
f(x) = (2x³ − 1)⁸
Външна: ( )⁸, вътрешна: 2x³−1
f'(x) = 8(2x³−1)⁷ · 6x² = 48x²(2x³−1)⁷
5
f(x) = √(1 − x²) = (1−x²)^(1/2)
Външна: ( )^(1/2), вътрешна: 1−x²
f'(x) = (1/2)(1−x²)^(−1/2) · (−2x) = −x/√(1−x²)
6
f(x) = x² · e^(sin x) — КОМБО
Произведение + верижно:
f'(x) = 2x·e^(sinx) + x²·e^(sinx)·cosx
= xe^(sinx)(2 + xcosx)
Блок 04
Arc функции — производни и домейни
Излязоха директно на миналия изпит!
⏱ ~15 мин
Таблица — Arc производни
f(x)f'(x)Домейн за f'
arcsin(x)1/√(1−x²)x ∈ (−1, 1)
arccos(x)−1/√(1−x²)x ∈ (−1, 1)
arctg(x)1/(1+x²)x ∈ ℝ
arcctg(x)−1/(1+x²)x ∈ ℝ
💡 Лесно запомняне:
• arcsin и arccos: знаменател √(1−x²), знаците са + и −
• arctg и arcctg: знаменател (1+x²), знаците са + и −
Arc + верижно правило
1
f(x) = arcsin(2x)
Верижно: f'(x) = 1/√(1−(2x)²) · 2 = 2/√(1−4x²)
2
f(x) = arctg(x²)
Верижно: f'(x) = 1/(1+(x²)²) · 2x = 2x/(1+x⁴)
3
f(x) = x · arctg(x) — от миналия изпит!
Произведение:
f'(x) = arctg(x) + x · 1/(1+x²)
= arctg(x) + x/(1+x²)
4
f(x) = arccos(√x)
Верижно (два слоя):
f'(x) = −1/√(1−(√x)²) · (1/2√x)
= −1/(2√x · √(1−x))
= −1/(2√(x(1−x)))
Производни на f(x) и f''(x) — от домашното
1
f(x) = x/(4−x²) — намери f' и f''
f': Частно: (4−x²+2x²)/(4−x²)² = (4+x²)/(4−x²)²
f'': Частно на f': 2x(4−x²)³ + 4x(4+x²)(4−x²) / (4−x²)⁴
Опростено: 2x(x²+12)/(4−x²)³
2
f(x) = x²/eˣ — намери f' и f''
f': x(2−x)/eˣ
f'': (x²−4x+2)/eˣ
3
f(x) = x·arctg(x) — намери f' и f''
f': arctg(x) + x/(1+x²)
f'': 1/(1+x²) + (1−x²)/(1+x²)² = 2/(1+x²)²
Блок 05
Задачи за преговор
Всички типове — намери f'(x)
⏱ ~45 мин
🟢 Основни формули + правила
ЗАДАЧА 01
СУМА
f(x) = 3x⁴ − 5x² + ln(x) − eˣ
👆 Кликни за решение
f'(x) = 12x³ − 10x + 1/x − eˣ
ЗАДАЧА 02
ПРОИЗВЕДЕНИЕ
f(x) = x³ · sin(x)
👆 Кликни за решение
f'(x) = 3x²·sinx + x³·cosx
= x²(3sinx + xcosx)
ЗАДАЧА 03
ЧАСТНО
f(x) = (x² + 1) / sin(x)
👆 Кликни за решение
f'(x) = [2x·sinx − (x²+1)·cosx] / sin²x
ЗАДАЧА 04
ЧАСТНО
f(x) = ln(x) / x²
👆 Кликни за решение
f=lnx, g=x²; f'=1/x, g'=2x
f'(x) = [(1/x)·x² − lnx·2x] / x⁴
= [x − 2xlnx] / x⁴
= (1 − 2lnx) / x³
🔵 Верижно правило
ЗАДАЧА 05
ВЕРИЖНО
f(x) = cos(x² − 3x)
👆 Кликни за решение
Външна: cos, вътрешна: x²−3x
f'(x) = −sin(x²−3x) · (2x−3)
ЗАДАЧА 06
ВЕРИЖНО
f(x) = e^(cos x)
👆 Кликни за решение
Външна: eˣ, вътрешна: cosx
f'(x) = e^(cosx) · (−sinx) = −sinx · e^(cosx)
ЗАДАЧА 07
ВЕРИЖНО
f(x) = ln(tg x)
👆 Кликни за решение
Външна: ln, вътрешна: tgx
f'(x) = 1/tgx · 1/cos²x
= cosx/sinx · 1/cos²x
= 1/(sinx·cosx) = 2/sin(2x)
ЗАДАЧА 08
ВЕРИЖНО
f(x) = √(x² + 2x + 5)
👆 Кликни за решение
Запиши: (x²+2x+5)^(1/2)
f'(x) = (1/2)(x²+2x+5)^(-1/2) · (2x+2)
= (x+1)/√(x²+2x+5)
🟡 Комбинирани — Произведение + Верижно
ЗАДАЧА 09
КОМБО
f(x) = x · ln(x² + 1)
👆 Кликни за решение
Произведение: f=x, g=ln(x²+1)
g' = 1/(x²+1)·2x = 2x/(x²+1) (верижно!)
f'(x) = ln(x²+1) + x·2x/(x²+1)
= ln(x²+1) + 2x²/(x²+1)
ЗАДАЧА 10
КОМБО
f(x) = sin²(x) · eˣ
👆 Кликни за решение
Произведение: f=sin²x, g=eˣ
f' = 2sinx·cosx = sin(2x) (верижно!)
f'(x) = sin(2x)·eˣ + sin²x·eˣ
= eˣ(sin2x + sin²x)
ЗАДАЧА 11
КОМБО
f(x) = e^(2x) / (x² + 1)
👆 Кликни за решение
Частно: f=e^(2x), g=x²+1
f' = 2e^(2x) (верижно!), g' = 2x
f'(x) = [2e^(2x)(x²+1) − e^(2x)·2x] / (x²+1)²
= 2e^(2x)(x²−x+1) / (x²+1)²
🔴 Arc функции
ЗАДАЧА 12
ARC
f(x) = arcsin(x/2)
👆 Кликни за решение
Верижно: вътрешна x/2, производна 1/2
f'(x) = 1/√(1−(x/2)²) · 1/2
= 1/√(4−x²)
ЗАДАЧА 13
ARC
f(x) = arctg(√x)
👆 Кликни за решение
Верижно: вътрешна √x = x^(1/2), производна 1/(2√x)
f'(x) = 1/(1+(√x)²) · 1/(2√x)
= 1/(1+x) · 1/(2√x)
= 1/(2√x·(1+x))
ЗАДАЧА 14
ARC + КОМБО
f(x) = x² · arcctg(x)
👆 Кликни за решение
Произведение: f=x², g=arcctg x
f'=2x, g'=−1/(1+x²)
f'(x) = 2x·arcctgx + x²·(−1/(1+x²))
= 2x·arcctgx − x²/(1+x²)
ЗАДАЧА 15 — f' И f''
ДВОЙНА
f(x) = x · arctg(x) — намери f' и f''
👆 Кликни за решение
f'(x):
Произведение: arctgx + x/(1+x²)

f''(x): Диференцираме f':
(arctgx)' = 1/(1+x²)
(x/(1+x²))' = [(1+x²)−x·2x]/(1+x²)² = (1−x²)/(1+x²)²
f''(x) = 1/(1+x²) + (1−x²)/(1+x²)²
= [(1+x²)+(1−x²)]/(1+x²)²
= 2/(1+x²)²
