Блок 01
Формулата за интегриране по части
⏱ ~15 мин
💡 Кога се използва?
Когато имаш произведение от два различни вида функции
?
Типичните случаи
• x · eˣ — полином × експонента
• x · sin x — полином × тригонометрична
• x · ln x — полином × логаритъм
• eˣ · sin x — експонента × тригонометрична
• ln x — само логаритъм (смята се като ln x · 1)

При тези случаи нито директното интегриране, нито смяната на променлива работят!
📋 Формулата
∫ u · dv = u · v − ∫ v · du
💡 Произходът: Формулата идва от правилото за производна на произведение:
(u·v)' = u'·v + u·v' → интегрираме двете страни → ∫u dv = uv − ∫v du

u — Избираш

Функцията която диференцираш.
Трябва да стане по-проста след диференциране.
du = u' dx

dv — Избираш

Остатъкът (включително dx).
Трябва лесно да се интегрира.
v = ∫ dv

Блок 02
LIATE — Как избираш u?
Най-важното правило за интегриране по части
⏱ ~20 мин
🎯 Правилото LIATE
Избираш u = функцията която е по-наляво в тази наредба
РЕД
БУКВА
ВИД ФУНКЦИЯ
1
L
Logarithm — Логаритми: ln x, log x
2
I
Inverse trig — Обратни тригон.: arcsin, arctan...
3
A
Algebraic — Алгебрични: x, x², x³...
4
T
Trigonometric — Тригон.: sin x, cos x...
5
E
Exponential — Експонента: eˣ, aˣ
💡 Как се ползва: Гледаш кои два вида функции имаш. u = тази с по-малък номер в LIATE. dv = тази с по-голям номер (+ dx).
📊 Примери за избор на u
Ex1
∫ x · eˣ dx
x е A(3), eˣ е E(5) → u = x, dv = eˣ dx
Ex2
∫ x · sin x dx
x е A(3), sin x е T(4) → u = x, dv = sin x dx
Ex3
∫ ln x dx
ln x е L(1), 1 е A(3) → u = ln x, dv = dx
(Пишем ln x · 1 dx)
Ex4
∫ x² · ln x dx
ln x е L(1), x² е A(3) → u = ln x, dv = x² dx
Ex5
∫ eˣ · sin x dx
sin x е T(4), eˣ е E(5) → u = sin x, dv = eˣ dx
(Специален случай — нужни са 2 интегрирания по части!)
Блок 03
Алгоритъм — Стъпка по стъпка
⏱ ~10 мин

⚡ Алгоритъм за интегриране по части

1
Разпознай — имаш ли произведение от два вида функции? Работи ли смяна на променлива? Ако не → интегриране по части.
2
Избери u и dv по правилото LIATE. Запиши ги ясно.
3
Намери du и v: du = u' dx и v = ∫ dv
4
Приложи формулата: ∫ u dv = u·v − ∫ v du
5
Реши новия интеграл ∫v du — той трябва да е по-прост! Ако не е — проверяваш избора на u.
6
Добави + C в края и провери с диференциране.
⚠️ Специални случаи
!
Двойно интегриране по части (eˣ·sin x)
При ∫ eˣ sin x dx прилагаш по части 2 пъти и получаваш
∫ eˣ sin x dx = ... − ∫ eˣ sin x dx
Местиш интеграла от дясно наляво и делиш!
2∫ eˣ sin x dx = ... → ∫ eˣ sin x dx = .../2
!
Повторно по части (x²·eˣ)
При ∫ x² eˣ dx прилагаш по части 2 пъти —
първо намаляш x² до x, после x до константа.
Блок 04
Пълни примери
Всяка стъпка изписана
⏱ ~30 мин
Пример 1 — ∫ x · eˣ dx
1
Избор по LIATE: x е A, eˣ е E
u = x     dv = eˣ dx
2
Намираме du и v
du = dx     v = eˣ
3
Прилагаме формулата
∫ x eˣ dx = x·eˣ − ∫ eˣ dx
= x·eˣ − eˣ + C
= eˣ(x − 1) + C
Пример 2 — ∫ x · cos x dx
1
u = x (A),   dv = cos x dx (T)
2
du = dx,   v = sin x
3
∫ x cos x dx = x·sin x − ∫ sin x dx
= x·sin x − (−cos x) + C
= x·sin x + cos x + C
Пример 3 — ∫ ln x dx
1
u = ln x (L),   dv = dx (пишем ln x · 1 dx)
2
du = (1/x) dx,   v = x
3
∫ ln x dx = x·ln x − ∫ x·(1/x) dx
= x·ln x − ∫ 1 dx
= x·ln x − x + C = x(ln x − 1) + C
Пример 4 — ∫ x² · eˣ dx (двойно по части)
1
u = x², dv = eˣ dx
du = 2x dx, v = eˣ
= x²eˣ − ∫ 2x eˣ dx
2
Прилагаме пак за ∫ 2x eˣ dx
u = 2x, dv = eˣ dx
du = 2 dx, v = eˣ
= 2x eˣ − ∫ 2eˣ dx = 2x eˣ − 2eˣ
3
Събираме
∫ x²eˣ dx = x²eˣ − (2xeˣ − 2eˣ) + C
= eˣ(x² − 2x + 2) + C
Пример 5 — ∫ eˣ · sin x dx (цикличен)
1
u = sin x, dv = eˣ dx
du = cos x dx, v = eˣ
∫eˣsin x dx = eˣsin x − ∫eˣcos x dx
2
Прилагаме пак за ∫eˣ cos x dx
u = cos x, dv = eˣ dx
du = −sin x dx, v = eˣ
= eˣcos x − ∫eˣ(−sin x)dx = eˣcos x + ∫eˣsin x dx
3
Заместваме и решаваме уравнението!
∫eˣsin x dx = eˣsin x − eˣcos x − ∫eˣsin x dx
2∫eˣsin x dx = eˣsin x − eˣcos x
∫eˣsin x dx = eˣ(sin x − cos x)/2 + C
Блок 05
Задачи за практика
Кликни за решение — но първо опитай сам!
⏱ ~60 мин
🟢 Лесни — Едно интегриране
ЗАДАЧА 01
∫ x · e^(2x) dx
💡 u = x (A), dv = e^(2x)dx (E)
👆 Кликни за решение
U =x
dV =e^(2x) dx
dU =dx
V =(1/2)e^(2x)
∫ x e^(2x) dx = x·(1/2)e^(2x) − ∫(1/2)e^(2x)dx
= (x/2)e^(2x) − (1/4)e^(2x) + C
= (e^(2x)/4)(2x − 1) + C
ЗАДАЧА 02
∫ x · sin(3x) dx
💡 u = x, dv = sin(3x)dx
👆 Кликни за решение
U =x
dV =sin(3x) dx
dU =dx
V =−(1/3)cos(3x)
= x·(−1/3)cos(3x) − ∫(−1/3)cos(3x)dx
= −(x/3)cos(3x) + (1/3)·(1/3)sin(3x) + C
= −(x/3)cos(3x) + (1/9)sin(3x) + C
ЗАДАЧА 03
∫ x · ln x dx
💡 u = ln x (L), dv = x dx (A)
👆 Кликни за решение
U =ln x
dV =x dx
dU =(1/x) dx
V =x²/2
= (x²/2)·ln x − ∫(x²/2)·(1/x)dx
= (x²/2)ln x − (1/2)∫x dx
= (x²/2)ln x − x²/4 + C
= (x²/4)(2ln x − 1) + C
ЗАДАЧА 04
∫ arctg(x) dx
💡 u = arctg x (I), dv = dx
👆 Кликни за решение
U =arctg x
dV =dx
dU =1/(1+x²) dx
V =x
= x·arctg x − ∫ x/(1+x²) dx
Новият интеграл: смяна t=1+x², dt=2x dx:
∫ x/(1+x²)dx = (1/2)ln(1+x²)
= x·arctg x − (1/2)ln(1+x²) + C
🟡 По-сложни — Двойно интегриране
ЗАДАЧА 05
∫ x² · cos x dx
💡 Прилагаш по части 2 пъти — степента намалява
👆 Кликни за решение
Първо: u=x², dv=cos x dx → du=2x dx, v=sin x
= x²sin x − ∫2x sin x dx

За ∫2x sin x dx: u=2x, dv=sin x dx → du=2dx, v=−cos x
= −2x cos x + ∫2cos x dx = −2x cos x + 2sin x

Финал:
= x²sin x − (−2x cos x + 2sin x) + C
= x²sin x + 2x cos x − 2sin x + C
ЗАДАЧА 06
∫ eˣ · cos x dx
💡 Цикличен случай — прилагаш 2 пъти и решаваш уравнение!
👆 Кликни за решение
Нека I = ∫eˣ cos x dx

u=cos x, dv=eˣdx → du=−sin x dx, v=eˣ
I = eˣcos x + ∫eˣsin x dx

За ∫eˣsin x dx: u=sin x, dv=eˣdx → du=cos x dx, v=eˣ
= eˣsin x − ∫eˣcos x dx = eˣsin x − I

Заместваме: I = eˣcos x + eˣsin x − I
2I = eˣ(cos x + sin x)
I = eˣ(cos x + sin x)/2 + C
ЗАДАЧА 07
∫ x² · ln x dx
💡 u = ln x (L), dv = x²dx
👆 Кликни за решение
U =ln x
dV =x² dx
dU =(1/x) dx
V =x³/3
= (x³/3)ln x − ∫(x³/3)·(1/x)dx
= (x³/3)ln x − (1/3)∫x²dx
= (x³/3)ln x − x³/9 + C
= (x³/9)(3ln x − 1) + C
ЗАДАЧА 08
∫ x · arcsin x dx
💡 u = arcsin x (I), dv = x dx (A)
👆 Кликни за решение
U =arcsin x
dV =x dx
dU =1/√(1−x²) dx
V =x²/2
= (x²/2)arcsin x − ∫(x²/2)/√(1−x²) dx
За ∫x²/(2√(1−x²))dx: t=1−x², dt=−2x dx (по-сложно)
Пренаписваме x²=1−(1−x²):
∫x²/√(1−x²)dx = ∫(1−(1−x²))/√(1−x²)dx
= ∫1/√(1−x²)dx − ∫√(1−x²)dx
= arcsin x − (x√(1−x²)/2 + arcsin x/2)
= (x²/2)arcsin x + (x√(1−x²))/4 − (arcsin x)/4 + C
