Блок 01
Защо ни трябва смяна на променлива?
⏱ ~15 мин
💡 Проблемът
Не всичко може да се интегрира директно по таблицата
?
Пример — Как изглежда проблемът
Знаеш от таблицата: ∫ eˣ dx = eˣ + C

Но какво правиш с: ∫ e^(3x) dx = ?

Не е директно от таблицата! Вътрешната функция е 3x, не просто x.

Решението: внасяш 3x под знака на диференциала — т.е. правиш смяна на променлива.
🔑 Ключовата идея — Диференциалът
Трябва да знаеш това преди всичко останало
Ако t = g(x), тогава dt = g'(x) dx
Ex
Ако t = 3x, тогава dt = 3 dx, откъдето dx = dt/3

Ако t = x², тогава dt = 2x dx, откъдето x dx = dt/2

Ако t = sin x, тогава dt = cos x dx

КОНСТАНТА ПОД d

Вътрешната функция е ax + b (линейна). Внасяш константата директно.

ФУНКЦИЯ ПОД d

Вътрешната функция е по-сложна. Трябва да намериш производната й в израза.

Блок 02
Внасяне на константа под диференциала
Най-лесният вид смяна на променлива
⏱ ~30 мин
📋 Формулата
∫ f(ax + b) dx = (1/a) · F(ax + b) + C
💡 С думи: Ако аргументът е линеен (ax+b), интегрираш нормално и делиш на коефициента пред x.
⚠️ Работи САМО когато вътрешната функция е линейна (ax+b). За по-сложни функции → следващия блок!
📘 Примери стъпка по стъпка
Ex1
∫ e^(3x) dx
Вътрешна функция: 3x, коефициент a=3
Интегрираме eˣ → eˣ, делим на 3:
= (1/3)e^(3x) + C

Проверка: [(1/3)e^(3x)]' = (1/3)·3·e^(3x) = e^(3x) ✓
Ex2
∫ sin(2x + 1) dx
Вътрешна: 2x+1, a=2
Интегрираме sin → −cos, делим на 2:
= −(1/2)cos(2x+1) + C
Ex3
∫ (4x − 3)⁵ dx
Вътрешна: 4x−3, a=4
Интегрираме xⁿ → xⁿ⁺¹/(n+1), делим на 4:
= (1/4)·(4x−3)⁶/6 + C
= (4x−3)⁶/24 + C
Ex4
∫ 1/(5x + 2) dx
Вид 1/x → ln|x|, вътрешна: 5x+2, a=5
= (1/5)ln|5x+2| + C
Ex5
∫ √(3x − 1) dx
Запиши: (3x−1)^(1/2), вътрешна: 3x−1, a=3
Интегрираме x^(1/2) → x^(3/2)/(3/2), делим на 3:
= (1/3)·(3x−1)^(3/2)/(3/2) + C
= (2/9)(3x−1)^(3/2) + C
Блок 03
Внасяне на функция под диференциала
Смяна на променлива t = g(x)
⏱ ~40 мин
🔑 Кога се прилага?
Когато в интеграла има функция и нейната производна
∫ f(g(x)) · g'(x) dx = F(g(x)) + C
💡 Патернът: Търсиш в интеграла функция g(x) и нейната производна g'(x) едновременно. Ако ги намериш — можеш да смениш t = g(x).
⚙️ Алгоритъм стъпка по стъпка
1
Избери t = g(x)
Избираш "вътрешната" функция. Обикновено е тази под корен, в степен, в тригонометрична функция и т.н.
2
Намери dt
dt = g'(x) dx → изразяваш g'(x) dx чрез dt
3
Замени в интеграла
Заменяш g(x) с t и g'(x)dx с dt. Трябва да остане само t — без x!
4
Интегрирай по t
Вече имаш прост интеграл от t — решаваш по таблицата.
5
Върни се към x
Заменяш t обратно с g(x) и добавяш + C.
📘 Примери
Ex1
∫ 2x · e^(x²) dx
Забелязваме: e^(x²) и 2x (производната на x²!)
t = x² → dt = 2x dx
Заменяме: ∫ eᵗ dt = eᵗ + C
Връщаме: = e^(x²) + C
Ex2
∫ cos(x) · e^(sin x) dx
Забелязваме: e^(sin x) и cos x (производната на sin x!)
t = sin x → dt = cos x dx
Заменяме: ∫ eᵗ dt = eᵗ + C
Връщаме: = e^(sin x) + C
Ex3
∫ x² / (x³ + 1) dx
Забелязваме: 1/(x³+1) и x² (почти производната на x³+1 = 3x²)
t = x³+1 → dt = 3x² dx → x² dx = dt/3
Заменяме: ∫ (1/t)·(dt/3) = (1/3)∫(1/t)dt = (1/3)ln|t| + C
Връщаме: = (1/3)ln|x³+1| + C
Ex4
∫ sin(x) / cos²(x) dx
Забелязваме: 1/cos²x и sin x (−производната на cos x)
t = cos x → dt = −sin x dx → sin x dx = −dt
Заменяме: ∫ (1/t²)·(−dt) = −∫t⁻² dt = −(t⁻¹/(−1)) + C = 1/t + C
Връщаме: = 1/cos x + C
Ex5
∫ tg(x) dx = ∫ sin(x)/cos(x) dx
t = cos x → dt = −sin x dx
∫ (−dt/t) = −ln|t| + C
Връщаме: = −ln|cos x| + C
Блок 04
Обобщен алгоритъм — Кое кога?
⏱ ~10 мин

⚡ Как избираш метода?

1
Директно от таблицата? — Ако изразът съвпада точно с табличен интеграл → решаваш веднага.
2
Вътрешната функция линейна ли е (ax+b)? — Константа под d: интегрираш и делиш на a.
3
Виждаш ли функция И нейната производна? — Функция под d: t = g(x), dt = g'(x)dx, заменяш.
4
Нищо не работи? — Вероятно трябва интегриране по части (Файл 3).
📊 Бързо разпознаване на патерните
→
∫ f(ax+b) dx → Константа: дели на a
→
∫ [g(x)]ⁿ · g'(x) dx → Функция: t=g(x)
→
∫ g'(x)/g(x) dx → Функция: t=g(x), резултат: ln|g(x)|+C
→
∫ e^(g(x)) · g'(x) dx → Функция: t=g(x), резултат: e^(g(x))+C
Блок 05
Задачи за практика
⏱ ~50 мин
🔵 Константа под диференциала
ЗАДАЧА 01
∫ cos(5x) dx
👆 Кликни за решение
Вътрешна: 5x, a=5
= (1/5)sin(5x) + C
ЗАДАЧА 02
∫ e^(−2x) dx
👆 Кликни за решение
Вътрешна: −2x, a=−2
= −(1/2)e^(−2x) + C
ЗАДАЧА 03
∫ (3x + 2)⁴ dx
👆 Кликни за решение
Вътрешна: 3x+2, a=3
= (1/3)·(3x+2)⁵/5 + C
= (3x+2)⁵/15 + C
ЗАДАЧА 04
∫ 1/(2x − 7) dx
👆 Кликни за решение
Вид 1/x → ln, a=2
= (1/2)ln|2x−7| + C
ЗАДАЧА 05
∫ sin(πx + 1) dx
👆 Кликни за решение
Вътрешна: πx+1, a=π
= −(1/π)cos(πx+1) + C
🟠 Функция под диференциала
ЗАДАЧА 06
∫ 3x² · (x³ + 5)⁴ dx
💡 Производната на x³+5 е 3x²!
👆 Кликни за решение
t = x³+5 → dt = 3x² dx
∫ t⁴ dt = t⁵/5 + C
= (x³+5)⁵/5 + C
ЗАДАЧА 07
∫ sin(x) · cos³(x) dx
💡 Производната на cos x е −sin x
👆 Кликни за решение
t = cos x → dt = −sin x dx → sin x dx = −dt
∫ t³·(−dt) = −t⁴/4 + C
= −cos⁴(x)/4 + C
ЗАДАЧА 08
∫ x / (x² + 1) dx
💡 Производната на x²+1 е 2x
👆 Кликни за решение
t = x²+1 → dt = 2x dx → x dx = dt/2
∫ (1/t)·(dt/2) = (1/2)ln|t| + C
= (1/2)ln(x²+1) + C
ЗАДАЧА 09
∫ eˣ / (eˣ + 3) dx
💡 Производната на eˣ+3 е eˣ!
👆 Кликни за решение
t = eˣ+3 → dt = eˣ dx
∫ (1/t) dt = ln|t| + C
= ln(eˣ+3) + C
ЗАДАЧА 10
∫ cos(x) · √(sin x) dx
💡 Производната на sin x е cos x
👆 Кликни за решение
t = sin x → dt = cos x dx
∫ √t dt = ∫ t^(1/2) dt = t^(3/2)/(3/2) + C
= (2/3)(sin x)^(3/2) + C
ЗАДАЧА 11
∫ (ln x)² / x dx
💡 Производната на ln x е 1/x!
👆 Кликни за решение
t = ln x → dt = (1/x) dx
∫ t² dt = t³/3 + C
= (ln x)³/3 + C
ЗАДАЧА 12 — По-сложна
∫ x · e^(x²+1) dx
💡 Производната на x²+1 е 2x — имаш x, трябва ти 2x!
👆 Кликни за решение
t = x²+1 → dt = 2x dx → x dx = dt/2
∫ eᵗ · (dt/2) = (1/2)eᵗ + C
= (1/2)e^(x²+1) + C
