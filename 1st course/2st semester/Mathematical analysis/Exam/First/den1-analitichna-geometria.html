sin x 0 1/2 √2/2 √3/2 1

tan x 0 √3/3 ≈0.577 1 √3 ≈1.73 ∞ (нма)
cot x ∞ (нма) √3 ≈1.73 1 √3/3 ≈0.577 0
💡 Трик за sin: стойностите са √0/2, √1/2, √2/2, √3/2, √4/2 = 0, 1/2, √2/2, √3/2, 1. За cos — обратно!
📝 Важни идентичности
Тези формули се ползват много на тест
①
Питагорова идентичност
sin²x + cos²x = 1
От тук: sin²x = 1 - cos²x и cos²x = 1 - sin²x
②
Тангенс и котангенс
tan x = sin x / cos x    cot x = cos x / sin x
③
Граничните случаи
sin 0 = 0, cos 0 = 1, sin(π/2) = 1, cos(π/2) = 0
④
Отрицателни ъгли
sin(-x) = -sin(x)    cos(-x) = cos(x)
sin е нечетна, cos е четна функция!

Допустими стойности (Domain)

Кога функцията е дефинирана?

⏱ ~1 ч
📋 Правилата — Наизуст!
Три основни ограничения
📌 ДРОБ
Знаменателят ≠ 0

Намираш кога = 0 и изключваш тези x-ове
📌 КОРЕН (четен)
Изразът под корена ≥ 0

Решаваш неравенство: изразът ≥ 0
📌 ЛОГАРИТЪМ
Аргументът > 0

Решаваш неравенство: изразът > 0
📌 КОМБИНАЦИЯ
Прилагаш всички правила и намираш пресечението им
⚠️ Важно: Когато нямаш нито корен, нито дроб, нито логаритъм — D(f) = ℝ (всички реални числа)!
📘 Примери стъпка по стъпка
Ex1
f(x) = √(x − 3)
Корен → изразът ≥ 0
x − 3 ≥ 0
x ≥ 3
D(f) = [3, +∞)
Ex2
f(x) = 1 / (x² − 4)
Дроб → знаменател ≠ 0
x² − 4 = 0 → x² = 4 → x = ±2
Изключваме x = 2 и x = −2
D(f) = ℝ \ {−2, 2}
Ex3
f(x) = log(2x + 1)
Логаритъм → аргументът > 0
2x + 1 > 0
2x > −1
x > −1/2
D(f) = (−1/2, +∞)
Ex4
f(x) = √(x² − 9)
Корен → x² − 9 ≥ 0
x² ≥ 9 → |x| ≥ 3
Значи: x ≤ −3 или x ≥ 3
D(f) = (−∞, −3] ∪ [3, +∞)
Ex5
f(x) = √(x − 1) / (x − 3)   [комбинирана!]
Корен: x − 1 ≥ 0 → x ≥ 1
Дроб: x − 3 ≠ 0 → x ≠ 3
Пресичаме: x ≥ 1 И x ≠ 3
D(f) = [1, 3) ∪ (3, +∞)
✏️ Задачи за практика
Кликни на задача за да видиш решението — но първо опитай сам!
ЗАДАЧА 01
f(x) = √(5 − x)
💡 Каква е условието за корен?
👆 Кликни за решение
Корен → изразът под корена ≥ 0
5 − x ≥ 0
−x ≥ −5
x ≤ 5 (знакът се обръща при деление с −1!)

D(f) = (−∞, 5]
ЗАДАЧА 02
f(x) = 1 / (x² + x − 6)
💡 Намери корените на знаменателя (разложи на множители)
👆 Кликни за решение
Дроб → знаменател ≠ 0
x² + x − 6 = 0
Разлагаме: (x + 3)(x − 2) = 0
x = −3 или x = 2

D(f) = ℝ \ {−3, 2}
ЗАДАЧА 03
f(x) = ln(3x − 6)
💡 Логаритъмът иска аргумент > 0
👆 Кликни за решение
Логаритъм → аргументът > 0
3x − 6 > 0
3x > 6
x > 2

D(f) = (2, +∞)
ЗАДАЧА 04
f(x) = √(x + 4) / (x² − 1)
💡 Комбинирана — прилагаш и двете правила!
👆 Кликни за решение
Условие 1 (корен): x + 4 ≥ 0 → x ≥ −4
Условие 2 (дроб): x² − 1 ≠ 0 → x ≠ ±1
Пресичаме x ≥ −4 с x ≠ −1 и x ≠ 1:

D(f) = [−4, −1) ∪ (−1, 1) ∪ (1, +∞)
ЗАДАЧА 05
f(x) = √(4 − x²)
💡 Разложи 4 − x² = (2−x)(2+x)
👆 Кликни за решение
Корен → 4 − x² ≥ 0
4 − x² ≥ 0 → x² ≤ 4 → |x| ≤ 2
Значи: −2 ≤ x ≤ 2

D(f) = [−2, 2]
ЗАДАЧА 06
f(x) = log₂(x² − 3x + 2)
💡 Разложи x² − 3x + 2 и намери кога > 0
👆 Кликни за решение
Логаритъм → x² − 3x + 2 > 0
Разлагаме: (x − 1)(x − 2) > 0
Произведението > 0 когато двата множителя имат еднакъв знак:
• x < 1: двата отрицателни → произведение положително ✓
• 1 < x < 2: (x−1) > 0, (x−2) < 0 → отрицателно ✗
• x > 2: двата положителни → положително ✓

D(f) = (−∞, 1) ∪ (2, +∞)
ЗАДАЧА 07
f(x) = √(x − 2) + ln(x + 1)
💡 Две условия едновременно — намери пресечението!
👆 Кликни за решение
Условие 1 (корен): x − 2 ≥ 0 → x ≥ 2
Условие 2 (логаритъм): x + 1 > 0 → x > −1
Пресичаме: x ≥ 2 И x > −1
По-строгото условие е x ≥ 2

D(f) = [2, +∞)
ЗАДАЧА 08
f(x) = 1/√(x − 5)
💡 Корен в знаменател → две условия наведнъж!
👆 Кликни за решение
Дроб → знаменателят ≠ 0
Корен → изразът ≥ 0, но тъй като е в знаменател → > 0 (строго!)
x − 5 > 0 → x > 5

D(f) = (5, +∞)

Графики на елементарни функции

Разпознавай формата по погледа

⏱ ~1.5 ч
🎨 Осемте основни графики
Нарисувани интерактивно — кликни на графика за детайли
📝 Ключови характеристики
Запомни тези за всяка функция
ФУНКЦИЯ
y = x² (парабола)
👆 Кликни за детайли
Форма: U-образна, симетрична спрямо y-оста
Минимум: (0, 0) — върхът на параболата
D(f) = ℝ, E(f) = [0, +∞)
Нули: x = 0
Нарастваща за x > 0, намаляваща за x < 0
ФУНКЦИЯ
y = x³ (кубична)
👆 Кликни за детайли
Форма: S-образна, нечетна функция (симетрична спрямо началото)
D(f) = ℝ, E(f) = ℝ
Нули: x = 0
Нарастваща навсякъде
Инфлексна точка: (0, 0)
ФУНКЦИЯ
y = √x (корен)
👆 Кликни за детайли
Форма: Започва от (0,0), расте но все по-бавно
D(f) = [0, +∞), E(f) = [0, +∞)
Нули: x = 0
Нарастваща навсякъде, но вдлъбната (расте бавно)
ФУНКЦИЯ
y = 1/x (хипербола)
👆 Кликни за детайли
Форма: Два клона в I и III квадрант
D(f) = ℝ \ {0}, E(f) = ℝ \ {0}
Асимптоти: x = 0 (вертикална), y = 0 (хоризонтална)
Нечетна функция: f(−x) = −f(x)
Нули: няма
ФУНКЦИЯ
y = eˣ (експонента)
👆 Кликни за детайли
Форма: Расте много бързо надясно, клони към 0 наляво
D(f) = ℝ, E(f) = (0, +∞)
Минава през: (0, 1) — защото e⁰ = 1
Хоризонтална асимптота: y = 0 (за x → −∞)
Нули: няма (винаги > 0)
ФУНКЦИЯ
y = ln(x) (натурален логаритъм)
👆 Кликни за детайли
Форма: Обратна на eˣ — отразена по y = x
D(f) = (0, +∞), E(f) = ℝ
Минава през: (1, 0) — защото ln(1) = 0
Вертикална асимптота: x = 0 (за x → 0⁺)
Нули: x = 1
ФУНКЦИЯ
y = sin(x)
👆 Кликни за детайли
Форма: Вълна, период 2π
D(f) = ℝ, E(f) = [−1, 1]
Нули: x = kπ (k целое число)
Максимум 1 при x = π/2 + 2kπ
Минимум −1 при x = −π/2 + 2kπ
Нечетна функция: sin(−x) = −sin(x)
ФУНКЦИЯ
y = cos(x)
👆 Кликни за детайли
Форма: Вълна, период 2π, изместена с π/2 спрямо sin
D(f) = ℝ, E(f) = [−1, 1]
Нули: x = π/2 + kπ
Максимум 1 при x = 2kπ (включително x = 0)
Минимум −1 при x = π + 2kπ
Четна функция: cos(−x) = cos(x)

Въведение в граници

Концепцията + базовите случаи

⏱ ~1 ч
💡 Какво е граница?
Разбери интуицията преди формулите
?
Идеята
lim(x→a) f(x) = L означава: Когато x се приближава към a (но не е равно на a), f(x) се приближава към L.

Важно: x никога не достига a — само се приближава!
1
Пример интуитивно
f(x) = x² при x → 3
x = 2.9 → f = 8.41
x = 2.99 → f = 8.9401
x = 2.999 → f = 8.994001
→ приближава се към 9
Значи: lim(x→3) x² = 9
📋 Основни правила за граници
Тези работят ако граничните стойности съществуват
lim(x→a) c = c      (граница на константа = константата)
lim(x→a) x = a      (граница на x = точката)
lim(x→a) [f(x) ± g(x)] = lim f(x) ± lim g(x)
lim(x→a) [f(x) · g(x)] = lim f(x) · lim g(x)
lim(x→a) f(x)/g(x) = lim f(x) / lim g(x)    [само ако знаменателят ≠ 0!]
💡 Директно заместване: Ако след заместване на x с a не получаваш 0/0, ∞/∞ или 0·∞ — просто замести и готово!
⚠️ Неопределени форми
Кога директното заместване НЕ работи
0/0
Нула разделена на нула — трябва факторизация или съкращение
∞/∞
Безкрайност върху безкрайност — деление по най-висока степен
0 · ∞
Нула по безкрайност — преобразуваш в дроб
∞ − ∞
Разлика от безкрайности — умножение по спрегнато
1∞
Единица на степен безкрайност — свежда се до числото e
⚠️ Ако получиш неопределена форма — СПРИ! Не пиши резултата, а приложи техника (ще учим утре детайлно).
✏️ Задачи — Директно заместване
Първо проверявай дали не получаваш неопределена форма!
ЗАДАЧА 01 — Лесна
lim(x→3) (x² + 2x − 1)
👆 Кликни за решение
Директно заместване: няма дроб, корен проблем.
x = 3: 3² + 2·3 − 1 = 9 + 6 − 1 = 14

Отговор: 14
ЗАДАЧА 02 — Лесна
lim(x→2) (x³ − 3x + 1)
👆 Кликни за решение
Директно заместване:
x = 2: 2³ − 3·2 + 1 = 8 − 6 + 1 = 3

Отговор: 3
ЗАДАЧА 03 — Дроб без проблем
lim(x→1) (x + 5) / (x + 2)
👆 Кликни за решение
Проверяваме знаменателя при x = 1: 1 + 2 = 3 ≠ 0 ✓
Директно заместване:
(1 + 5) / (1 + 2) = 6/3 = 2

Отговор: 2
ЗАДАЧА 04 — Неопределена форма!
lim(x→2) (x² − 4) / (x − 2)
👆 Кликни за решение
Опитваме директно при x = 2: (4 − 4)/(2 − 2) = 0/0 ⚠️ Неопределена форма!

Факторизираме числителя:
x² − 4 = (x − 2)(x + 2)
lim (x−2)(x+2)/(x−2) = lim (x+2) (съкращаваме x−2)
При x → 2: 2 + 2 = 4

Отговор: 4
ЗАДАЧА 05 — Неопределена форма!
lim(x→3) (x² − 9) / (x − 3)
👆 Кликни за решение
При x = 3: (9 − 9)/(3 − 3) = 0/0 ⚠️

Факторизираме:
x² − 9 = (x − 3)(x + 3)
lim (x−3)(x+3)/(x−3) = lim (x+3)
При x → 3: 3 + 3 = 6

Отговор: 6
ЗАДАЧА 06 — Граница при безкрайност
lim(x→∞) (3x + 1) / (x − 2)
👆 Кликни за решение
При x → ∞: горе и долу → ∞, форма ∞/∞ ⚠️

Делим горе и долу по x (най-висока степен):
(3x/x + 1/x) / (x/x − 2/x) = (3 + 1/x) / (1 − 2/x)
При x → ∞: 1/x → 0
= (3 + 0) / (1 − 0) = 3/1 = 3

Отговор: 3
