Arc (обратни тригонометрични) функции

Обратното на sin, cos, tan, cot

⏱ ~45 мин
💡 Какво означава "arc"?
Логиката зад обратните функции
?
Идеята
Ако sin(π/6) = 1/2, тогава arcsin(1/2) = π/6

arcsin пита: "За кой ъгъл x е sin(x) = дадена стойност?"
Аналогично за arccos, arctan, arccot.
⚠️ Важно: Arc функциите НЕ са 1/sin(x)! Това е sin⁻¹(x) като нотация за обратна функция, не степен −1!

🔗 Важни идентичности
arcsin(x) + arccos(x) = π/2
arctan(x) + arccot(x) = π/2
arcsin(−x) = −arcsin(x)    [нечетна]
arccos(−x) = π − arccos(x)
arctan(−x) = −arctan(x)    [нечетна]
💡 Полезно: arcsin(x) + arccos(x) = π/2 означава, че ако знаеш едното, автоматично намираш другото!
∞ Гранични стойности на arc функциите
lim(x→+∞) arctan(x) = π/2
lim(x→−∞) arctan(x) = −π/2
lim(x→+∞) arccot(x) = 0
lim(x→−∞) arccot(x) = π
💡 arctan има хоризонтални асимптоти y = π/2 и y = −π/2. arccot има асимптоти y = 0 и y = π.
✏️ Примерни задачи с arc функции
ЗАДАЧА 01
arcsin(√2/2) = ?
👆 Кликни за решение
Питаме: за кой ъгъл sin = √2/2?
От тригонометричната таблица: sin(π/4) = √2/2
Отговор: π/4 (45°)
ЗАДАЧА 02
arccos(−1/2) = ?
👆 Кликни за решение
Питаме: за кой ъгъл cos = −1/2? (обхватът е [0,π])
cos(2π/3) = −1/2
Отговор: 2π/3 (120°)
ЗАДАЧА 03
arctan(1) = ?
👆 Кликни за решение
Питаме: за кой ъгъл tan = 1?
tan(π/4) = 1
Отговор: π/4
ЗАДАЧА 04 — Граница
lim(x→∞) arctan(x²− 3x + 1)
💡 При x→∞ какво прави x²−3x+1?
👆 Кликни за решение
При x→∞: x²−3x+1 → +∞
lim(x→∞) arctan(+∞) = π/2
Отговор: π/2
ЗАДАЧА 05 — Граница
lim(x→−∞) arccot(2x + 1)
💡 При x→−∞ какво прави 2x+1?
👆 Кликни за решение
При x→−∞: 2x+1 → −∞
lim(x→−∞) arccot(−∞) = π
Отговор: π

Техники за намиране на граници

5 метода — кога и как да ги прилагаш

⏱ ~1 ч
🗺️ Алгоритъм — Как да избереш техника
1
Опитай директно заместване
Замести x = a. Ако получиш нормален резултат (не 0/0, ∞/∞, 0·∞) → готово!
2
Ако получиш 0/0 → Факторизация
Разложи числителя и/или знаменателя. Съкрати общия множител.
3
Ако имаш корени → Спрегнато
Умножи по спреженото изражение за да се отървеш от корена.
4
Ако x→∞ → Деление по най-висока степен
Дели числител и знаменател по xⁿ (най-голямата степен).
5
Ако имаш sin/cos около 0 → Специални граници
Използвай lim sin(x)/x = 1 и производните формули.
T1 Директно заместване
Замести x = a директно. Работи когато няма неопределена форма.
Пример: lim(x→2) (x³+1) = 2³+1 = 9
T2 Факторизация (за 0/0)
Разлагай! Търси (x−a) в числител и знаменател, съкращавай.
Ex
lim(x→1) (x³−1)/(x−1)
x³−1 = (x−1)(x²+x+1)
= lim (x²+x+1) = 1+1+1 = 3
💡 Полезни разложения:
x²−a² = (x−a)(x+a)
x³−a³ = (x−a)(x²+ax+a²)
x³+a³ = (x+a)(x²−ax+a²)
T3 Умножение по спрегнато (при корени)
Умножи по (√A + √B)/(√A + √B) за да елиминираш корена.
Ex
lim(x→0) (√(x+1) − 1)/x → форма 0/0
Умножаваме по (√(x+1)+1)/(√(x+1)+1):
= (x+1−1) / [x(√(x+1)+1)]
= x / [x(√(x+1)+1)]
= 1/(√(x+1)+1) → при x→0: 1/2
T4 Граница при безкрайност (∞/∞)
Дели числител и знаменател по xⁿ (най-голямата степен в целия израз).
🧠 Бързо правило за рационални функции при x→∞:

• Степен горе < степен долу → граница = 0
• Степен горе = степен долу → граница = водещи коефициенти
• Степен горе > степен долу → граница = ±∞
Ex
lim(x→∞) (3x²+x) / (2x²−5)
Делим по x²: (3+1/x)/(2−5/x²)
При x→∞: (3+0)/(2−0) = 3/2
T5 Едностранни граници
lim(x→a⁺) и lim(x→a⁻) — подхождаш от дясно и ляво
Ex
lim(x→0⁺) 1/x = +∞ (от дясно → положителни x)
lim(x→0⁻) 1/x = −∞ (от ляво → отрицателни x)
Границата не съществува (лява ≠ дясна)

Специални граници

Учи наизуст — излизат директно на теста

⏱ ~30 мин
🌟 Задължителни специални граници
lim(x→0) sin(x)/x = 1
lim(x→0) tan(x)/x = 1
lim(x→0) (1 − cos x)/x² = 1/2
lim(x→0) arcsin(x)/x = 1
lim(x→0) arctan(x)/x = 1
lim(x→∞) (1 + 1/x)ˣ = e
lim(x→0) (1 + x)^(1/x) = e
lim(x→0) (eˣ − 1)/x = 1
lim(x→0) ln(1+x)/x = 1
💡 Обща логика: Много специални граници около 0 се свеждат до "функция / нейния аргумент = 1". Ако видиш sin(нещо)/(същото нещо) → веднага = 1!
🔧 Как да прилагаш специалните граници
Ex1
lim(x→0) sin(3x)/x
Искаме sin(3x)/(3x) = 1, но имаме sin(3x)/x.
Умножаваме и делим по 3:
= 3 · sin(3x)/(3x) = 3 · 1 = 3
Ex2
lim(x→0) sin(5x)/sin(3x)
= sin(5x)/(5x) · (5x)/(3x) · (3x)/sin(3x)
= 1 · 5/3 · 1 = 5/3
Ex3
lim(x→0) (e^(2x) − 1)/x
Умножаваме и делим по 2:
= 2 · (e^(2x) − 1)/(2x) = 2 · 1 = 2
Ex4
lim(x→0) arctan(4x)/(2x)
= (4/2) · arctan(4x)/(4x) = 2 · 1 = 2

Задачи за практика

Всички техники — кликни за решение

⏱ ~1.5 ч
🟣 Факторизация
ЗАДАЧА 01
lim(x→2) (x² − 4) / (x² − 3x + 2)
💡 Разложи и числителя и знаменателя
👆 Кликни за решение
Числител: x²−4 = (x−2)(x+2)
Знаменател: x²−3x+2 = (x−2)(x−1)
= (x+2)/(x−1) → при x=2: 4/1 = 4
ЗАДАЧА 02
lim(x→−1) (x³ + 1) / (x + 1)
💡 x³+1 = (x+1)(x²−x+1)
👆 Кликни за решение
x³+1 = (x+1)(x²−x+1)
= x²−x+1 → при x=−1: 1+1+1 = 3
ЗАДАЧА 03
lim(x→3) (x² − 7x + 12) / (x² − 9)
👆 Кликни за решение
Числител: (x−3)(x−4)
Знаменател: (x−3)(x+3)
= (x−4)/(x+3) → при x=3: −1/6 = −1/6
🟠 Спрегнато (корени)
ЗАДАЧА 04
lim(x→4) (√x − 2) / (x − 4)
💡 Умножи по (√x + 2)/(√x + 2)
👆 Кликни за решение
· (√x+2)/(√x+2) = (x−4)/[(x−4)(√x+2)]
= 1/(√x+2) → при x=4: 1/(2+2) = 1/4
ЗАДАЧА 05
lim(x→0) (√(1+x) − √(1−x)) / x
👆 Кликни за решение
Умножаваме по (√(1+x)+√(1−x)):
[(1+x)−(1−x)] / [x(√(1+x)+√(1−x))]
= 2x / [x(√(1+x)+√(1−x))]
= 2/(√1+√1) = 2/2 = 1
🔵 При безкрайност
ЗАДАЧА 06
lim(x→∞) (5x³ − x) / (2x³ + 7)
👆 Кликни за решение
Делим по x³:
(5 − 1/x²) / (2 + 7/x³) → 5/2 = 5/2
ЗАДАЧА 07
lim(x→∞) (x² + 3x) / (x³ − 1)
💡 Степен горе < степен долу → ?
👆 Кликни за решение
Степен горе (2) < степен долу (3) → граница = 0
Проверка: делим по x³: (1/x + 3/x²)/(1 − 1/x³) → 0/1 = 0
ЗАДАЧА 08
lim(x→∞) √(x² + x) − x
💡 Умножи по спреженото!
👆 Кликни за решение
Умножаваме по (√(x²+x)+x):
[(x²+x)−x²] / (√(x²+x)+x) = x/(√(x²+x)+x)
Делим по x: 1/(√(1+1/x)+1)
При x→∞: 1/(1+1) = 1/2
🟢 Специални граници
ЗАДАЧА 09
lim(x→0) sin(7x) / (2x)
👆 Кликни за решение
= (7/2) · sin(7x)/(7x) = 7/2 · 1 = 7/2
ЗАДАЧА 10
lim(x→0) (1 − cos x) / x²
👆 Кликни за решение
Директно специална граница:
lim(x→0) (1−cos x)/x² = 1/2
ЗАДАЧА 11
lim(x→0) (e^(3x) − 1) / (5x)
👆 Кликни за решение
= (3/5) · (e^(3x)−1)/(3x) = 3/5 · 1 = 3/5
ЗАДАЧА 12 — Arc
lim(x→0) arcsin(2x) / (3x)
👆 Кликни за решение
= (2/3) · arcsin(2x)/(2x) = 2/3 · 1 = 2/3
