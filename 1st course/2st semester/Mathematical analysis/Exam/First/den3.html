Научи ги наизуст в този ред
#СтъпкаКакво правиш
1Дефиниционно множествоНамираш D(f) — кога функцията е дефинирана
2Четност / НечетностПроверяваш f(−x): = f(x) четна, = −f(x) нечетна, иначе — нито
3Нули на функциятаРешаваш f(x) = 0

7Вертикални асимптотиВ точките x = a ∉ D(f) където |f(x)| → ∞
8Наклонени асимптотиk = lim f(x)/x; b = lim [f(x)−kx]; y = kx+b

10Нарастване/Намаляванеf' > 0 → нараства; f' < 0 → намалява
11Локални екстремумиВ критичните точки: ако f' сменя знак → екстремум

13Изпъкналост/Вдлъбнатостf'' > 0 → изпъкнала надолу (U); f'' < 0 → вдлъбната (∩)

🧠 Ключови правила за знаците
f'
Първа производна → Монотонност & Екстремуми
f' > 0 → нарастваща | f' < 0 → намаляваща
Критична точка x₀: f'(x₀) = 0 или f' не съществува
• f' сменя + → − : локален максимум
• f' сменя − → + : локален минимум
• f' не сменя знак: нито максимум, нито минимум
f''
Втора производна → Изпъкналост & Инфлексни точки
f'' > 0 → изпъкнала надолу (U-форма, вдлъбната нагоре)
f'' < 0 → изпъкнала нагоре (∩-форма, вдлъбната надолу)
Инфлексна точка: там където f'' сменя знак

Асимптоти

Три вида — формули и примери

⏱ ~30 мин
1️⃣ Вертикални асимптоти
x = a — вертикална права
Вертикална асимптота x = a ако: lim(x→a⁺) f(x) = ±∞ или lim(x→a⁻) f(x) = ±∞
Ex
f(x) = 1/(x−2) → точката x = 2 ∉ D(f)
lim(x→2⁺) 1/(x−2) = +∞
lim(x→2⁻) 1/(x−2) = −∞
Вертикална асимптота: x = 2
2️⃣ Хоризонтални асимптоти
y = L — хоризонтална права
Хоризонтална асимптота y = L ако: lim(x→+∞) f(x) = L или lim(x→−∞) f(x) = L
Ex
f(x) = (2x+1)/(x−3)
lim(x→∞) (2x+1)/(x−3) = 2
Хоризонтална асимптота: y = 2
💡 Ако има хоризонтална асимптота с k=0, няма наклонена асимптота (и обратното)!
3️⃣ Наклонени асимптоти
y = kx + b — наклонена права
k = lim(x→∞) f(x)/x
b = lim(x→∞) [f(x) − kx]
Ex
f(x) = (x² + 1)/x = x + 1/x
k = lim(x²+1)/x² = 1
b = lim [(x²+1)/x − x] = lim 1/x = 0
Наклонена асимптота: y = x
⚠️ Наклонена асимптота търсиш САМО ако няма хоризонтална (k ≠ 0). Ако lim f(x)/x = 0, то асимптотата е хоризонтална y=b.
📈

f(−x) = ((−x)²−1)/((−x)²−4) = (x²−1)/(x²−4) = f(x)

5
Граници
lim(x→∞) (x²−1)/(x²−4) = 1 (хориз. асимптота)
lim(x→2⁺) = +∞; lim(x→2⁻) = −∞ → x=2 верт. асимптота
lim(x→−2⁺) = −∞; lim(x→−2⁻) = +∞ → x=−2 верт. асимптота
6-8
Асимптоти
Хоризонтална: y = 1
Вертикални: x = 2, x = −2
Наклонена: няма (има хоризонтална)
9
Първа производна
f'(x) = [2x(x²−4) − (x²−1)·2x] / (x²−4)²
= [2x³−8x − 2x³+2x] / (x²−4)²
= −6x / (x²−4)²
f'(x) = 0 → x = 0
Критична точка: x = 0
10-11
Монотонност & Екстремуми
f'(x) = −6x/(x²−4)²; знаменателят винаги > 0
• x < 0 (и x≠−2): −6x > 0 → f' > 0 → нараства
• x > 0 (и x≠2): −6x < 0 → f' < 0 → намалява
При x=0: f' сменя + → − → локален максимум
f(0) = (0−1)/(0−4) = 1/4
Максимум: (0, 1/4)
12
Втора производна
f''(x) = [−6(x²−4)² − (−6x)·2(x²−4)·2x] / (x²−4)⁴
= [−6(x²−4) + 24x²] / (x²−4)³
= (18x²+24) / (x²−4)³
Числителят 18x²+24 > 0 винаги!
f''(x) = 0 → няма реални решения
13-14
Изпъкналост & Инфлексни точки
Знакът на f'' се определя от (x²−4)³:
• |x| > 2: (x²−4)³ > 0 → f'' > 0 → изпъкнала надолу (U)
• |x| < 2: (x²−4)³ < 0 → f'' < 0 → вдлъбната (∩)
Инфлексни точки: няма (f'' не сменя знак в D(f))

Пример 2 — Пълно изследване

f(x) = x·eˣ

⏱ ~40 мин
f(x) = x · eˣ
Следваме алгоритъма
1
Дефиниционно множество
D(f) = ℝ (няма ограничения)
2
Четност
f(−x) = (−x)·e^(−x) = −xe^(−x) ≠ f(x) и ≠ −f(x)
Нито четна, нито нечетна
3
Нули
x·eˣ = 0 → x = 0 (eˣ > 0 винаги!)
Нула: x = 0
4
Знак
eˣ > 0 винаги → знакът = знака на x
• x < 0: f(x) < 0 | • x > 0: f(x) > 0
5-8
Граници & Асимптоти
lim(x→+∞) xeˣ = +∞ (и двете → +∞)
lim(x→−∞) xeˣ = 0 (форма −∞·0; eˣ → 0 по-бързо)
Хоризонтална асимптота: y = 0 (за x→−∞)
Вертикални: няма | Наклонени: няма
9
Първа производна
f'(x) = (x)'·eˣ + x·(eˣ)' = eˣ + x·eˣ = eˣ(1 + x)
f'(x) = 0 → eˣ(1+x) = 0 → x = −1
Критична точка: x = −1
10-11
Монотонност & Екстремуми
eˣ > 0 винаги → знакът = знака на (1+x)
• x < −1: (1+x) < 0 → f' < 0 → намалява
• x > −1: (1+x) > 0 → f' > 0 → нараства
f' сменя − → + при x=−1 → локален минимум
f(−1) = (−1)·e^(−1) = −1/e
Минимум: (−1, −1/e)
12
Втора производна
f''(x) = [eˣ(1+x)]' = eˣ(1+x) + eˣ·1 = eˣ(2+x)
f''(x) = 0 → x = −2
13-14
Изпъкналост & Инфлексни точки
Знакът = знака на (2+x):
• x < −2: f'' < 0 → вдлъбната (∩)
• x > −2: f'' > 0 → изпъкнала надолу (U)
f'' сменя знак при x=−2 → инфлексна точка!
f(−2) = −2·e^(−2) = −2/e²
Инфлексна точка: (−2, −2/e²)

Задачи за практика

Изследвай функциите по алгоритъма

⏱ ~1.5 ч
Задачи по отделни стъпки
Не е нужно да правиш пълно изследване — само посочената стъпка
ЗАДАЧА 01 — Асимптоти
f(x) = (2x² + 1) / (x² − x − 2)
💡 Намери всички асимптоти
👆 Кликни за решение
D(f): x²−x−2 = (x−2)(x+1) = 0 → x≠2, x≠−1

Вертикални: x = 2, x = −1 (границите → ±∞)

Хоризонтална: lim(x→∞) (2x²+1)/(x²−x−2) = 2/1 = y = 2

Наклонена: няма (има хоризонтална)
ЗАДАЧА 02 — Екстремуми
f(x) = x³ − 3x + 2
💡 Намери f', критичните точки и определи вида им
👆 Кликни за решение
f'(x) = 3x² − 3 = 3(x²−1) = 3(x−1)(x+1)
f'(x) = 0 → x = ±1

Знак на f':
• x < −1: f' > 0 нараства
• −1 < x < 1: f' < 0 намалява
• x > 1: f' > 0 нараства

Максимум при x=−1: f(−1) = −1+3+2 = 4 → точка (−1, 4)
Минимум при x=1: f(1) = 1−3+2 = 0 → точка (1, 0)
ЗАДАЧА 03 — Инфлексни точки
f(x) = x⁴ − 6x²
💡 Намери f'' и определи инфлексните точки
👆 Кликни за решение
f'(x) = 4x³ − 12x
f''(x) = 12x² − 12 = 12(x²−1) = 12(x−1)(x+1)
f''(x) = 0 → x = ±1

Знак на f'':
• x < −1: f'' > 0 (U)
• −1 < x < 1: f'' < 0 (∩)
• x > 1: f'' > 0 (U)

f'' сменя знак при x=±1 →
Инфлексни точки: (−1, −5) и (1, −5)
f(1) = 1−6 = −5 ✓
ЗАДАЧА 04 — Пълно изследване (кратко)
f(x) = x / (x + 1)
💡 Намери D(f), нули, асимптоти, монотонност
👆 Кликни за решение
D(f): x ≠ −1 → ℝ\{−1}

Нули: x = 0

Асимптоти:
• Вертикална: x = −1
• Хоризонтална: lim x/(x+1) = 1 → y = 1

f'(x): правило за частно:
f'(x) = [1·(x+1) − x·1]/(x+1)² = 1/(x+1)²
f'(x) > 0 винаги (освен x=−1) → нараства навсякъде
Екстремуми: няма

f''(x): −2/(x+1)³
• x < −1: f'' > 0 (U) | x > −1: f'' < 0 (∩)
Инфлексни точки: няма (x=−1 не е в D(f))
ЗАДАЧА 05 — Пълно изследване
f(x) = x² · e^(−x)
💡 Използвай правилото за произведение + верижно
👆 Кликни за решение
D(f) = ℝ
Нули: x = 0
Знак: x²≥0 и e^(−x)>0 → f(x) ≥ 0 (само при x=0 е 0)

Граници:
lim(x→+∞) x²e^(−x) = 0 (e^(−x) побеждава) → y=0 хориз. асимптота
lim(x→−∞) x²e^(−x) = +∞

f'(x): 2x·e^(−x) + x²·(−e^(−x)) = e^(−x)(2x−x²) = xe^(−x)(2−x)
f'=0 → x=0 или x=2
• x<0: f'<0 | 0<x<2: f'>0 | x>2: f'<0
Минимум (0,0), Максимум (2, 4e⁻²) = (2, 4/e²)

f''(x): e^(−x)(x²−4x+2)
f''=0 → x = 2±√2
Инфлексни точки при x = 2−√2 ≈ 0.59 и x = 2+√2 ≈ 3.41
