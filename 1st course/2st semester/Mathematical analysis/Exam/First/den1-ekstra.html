Правила за диференциране

Как да диференцираш комбинации от функции

⏱ ~25 мин
Четирите основни правила
📌 КОНСТАНТА × ФУНКЦИЯ
(c·f)' = c·f'

Пример:
(5x³)' = 5·3x² = 15x²
📌 СУМА / РАЗЛИКА
(f ± g)' = f' ± g'

Пример:
(x² + sin x)' = 2x + cos x
📌 ПРОИЗВЕДЕНИЕ
(f·g)' = f'g + fg'

Пример:
(x²·eˣ)' = 2x·eˣ + x²·eˣ
📌 ЧАСТНО
(f/g)' = (f'g - fg')/g²

Пример:
(sin x/x)' = (cos x·x - sin x·1)/x²
⚠️ Честа грешка: При правилото за частно — ВИНАГИ е (f'g − fg') / g². Не бъркай реда на изваждане!
Примери стъпка по стъпка
Ex1
f(x) = 3x⁴ − 2x² + 7x − 1
Правило за сума/разлика + константа:
f'(x) = 3·4x³ − 2·2x + 7·1 − 0
f'(x) = 12x³ − 4x + 7
Ex2
f(x) = x³ · sin(x)
Правило за произведение: f = x³, g = sin x
f'(x) = 3x² · sin x + x³ · cos x
Ex3
f(x) = eˣ / x²
Правило за частно: f = eˣ, g = x²
f'(x) = (eˣ · x² − eˣ · 2x) / x⁴
= eˣ(x² − 2x) / x⁴ = eˣ(x − 2) / x³

Верижното правило

За сложни (композирани) функции — най-важното!

⏱ ~30 мин
Какво е верижното правило?
Когато имаш функция вътре в друга функция
[f(g(x))]' = f'(g(x)) · g'(x)
💡 С думи: "Производна на външната функция (оставяш вътрешната непроменена) × производна на вътрешната функция"
1
Идентифицирай външната и вътрешната функция
Пример: sin(x²) → външна: sin( ), вътрешна: x²
2
Диференцирай външната — оставяш вътрешната
[sin(x²)]' → cos(x²) · ...
3
Умножи по производната на вътрешната
cos(x²) · (x²)' = cos(x²) · 2x
Отговор: 2x · cos(x²)
Примери — от лесни към трудни
Ex1
(x² + 1)⁵
Външна: ( )⁵, вътрешна: x² + 1
= 5(x²+1)⁴ · (x²+1)'
= 5(x²+1)⁴ · 2x
= 10x(x²+1)⁴
Ex2
e^(3x+1)
Външна: eˣ, вътрешна: 3x+1
= e^(3x+1) · (3x+1)'
= e^(3x+1) · 3
= 3e^(3x+1)
Ex3
ln(x² − 4)
Външна: ln( ), вътрешна: x² − 4
= 1/(x²−4) · (x²−4)'
= 1/(x²−4) · 2x
= 2x/(x²−4)
Ex4
√(3x − 1) = (3x−1)^(1/2)
Външна: ( )^(1/2), вътрешна: 3x−1
= (1/2)(3x−1)^(-1/2) · 3
= 3 / (2√(3x−1))
= 3/(2√(3x−1))
Ex5
sin²(x) = [sin(x)]²
Външна: ( )², вътрешна: sin(x)
= 2sin(x) · (sin x)'
= 2sin(x) · cos(x)
= 2sin(x)cos(x) = sin(2x)
Ex6
e^(sin x) · x²  [верижно + произведение]
Произведение: f = e^(sin x), g = x²
f' = e^(sin x) · cos x (верижно!)
g' = 2x
= e^(sin x)·cos x · x² + e^(sin x) · 2x
= x·e^(sin x)(x·cos x + 2)
⚠️ Честа грешка: Хората забравят да умножат по производната на вътрешната функция. Винаги проверявай — умножил ли си по g'(x)?

Задачи за практика

Намери производната — кликни за решение

⏱ ~45 мин
🟢 Лесни — Основни формули
ЗАДАЧА 01
f(x) = 5x³ − 4x + 2
👆 Кликни за решение
f'(x) = 15x² − 4
ЗАДАЧА 02
f(x) = x⁷ − 3x⁵ + x
👆 Кликни за решение
f'(x) = 7x⁶ − 15x⁴ + 1
ЗАДАЧА 03
f(x) = eˣ + ln(x) − cos(x)
👆 Кликни за решение
f'(x) = eˣ + 1/x + sin(x)
ЗАДАЧА 04
f(x) = √x + 1/x²
💡 Запиши като степени: x^(1/2) + x^(-2)
👆 Кликни за решение
f(x) = x^(1/2) + x^(-2)
f'(x) = (1/2)x^(-1/2) + (-2)x^(-3)
= 1/(2√x) − 2/x³
🟡 Средни — Правила
ЗАДАЧА 05
f(x) = x² · eˣ
💡 Правило за произведение
👆 Кликни за решение
f = x², g = eˣ; f' = 2x, g' = eˣ
f'(x) = 2x·eˣ + x²·eˣ = eˣ(2x + x²) = x·eˣ(x+2)
ЗАДАЧА 06
f(x) = sin(x) · cos(x)
💡 Правило за произведение
👆 Кликни за решение
f = sin x, g = cos x; f' = cos x, g' = −sin x
f'(x) = cos x · cos x + sin x · (−sin x)
= cos²x − sin²x = cos(2x)
ЗАДАЧА 07
f(x) = (x² + 1) / (x − 1)
💡 Правило за частно
👆 Кликни за решение
f = x²+1, g = x−1; f' = 2x, g' = 1
f'(x) = [2x(x−1) − (x²+1)·1] / (x−1)²
= [2x²−2x − x²−1] / (x−1)²
= (x²−2x−1) / (x−1)²
ЗАДАЧА 08
f(x) = ln(x) / x
💡 Правило за частно
👆 Кликни за решение
f = ln x, g = x; f' = 1/x, g' = 1
f'(x) = [(1/x)·x − ln x·1] / x²
= [1 − ln x] / x²
🔴 По-сложни — Верижно правило
ЗАДАЧА 09
f(x) = (2x + 3)⁶
👆 Кликни за решение
Външна: ( )⁶, вътрешна: 2x+3
f'(x) = 6(2x+3)⁵ · 2 = 12(2x+3)⁵
ЗАДАЧА 10
f(x) = sin(3x² − 1)
👆 Кликни за решение
Външна: sin( ), вътрешна: 3x²−1
f'(x) = cos(3x²−1) · 6x = 6x·cos(3x²−1)
ЗАДАЧА 11
f(x) = e^(x² + 2x)
👆 Кликни за решение
Външна: eˣ, вътрешна: x²+2x
f'(x) = e^(x²+2x) · (2x+2) = (2x+2)·e^(x²+2x)
ЗАДАЧА 12
f(x) = ln(sin x)
👆 Кликни за решение
Външна: ln( ), вътрешна: sin x
f'(x) = 1/sin x · cos x = cos x / sin x = cot x
ЗАДАЧА 13
f(x) = √(x² + 4x + 1)
👆 Кликни за решение
Запиши: (x²+4x+1)^(1/2); вътрешна: x²+4x+1
f'(x) = (1/2)(x²+4x+1)^(-1/2) · (2x+4)
= (2x+4) / (2√(x²+4x+1))
= (x+2) / √(x²+4x+1)
ЗАДАЧА 14 — КОМБО
f(x) = x · e^(2x)
💡 Произведение + верижно правило
👆 Кликни за решение
Произведение: f = x, g = e^(2x)
f' = 1; g' = e^(2x)·2 = 2e^(2x) (верижно!)
f'(x) = 1·e^(2x) + x·2e^(2x)
= e^(2x)(1 + 2x)
