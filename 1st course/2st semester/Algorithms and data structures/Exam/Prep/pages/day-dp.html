🧠 Що е то Динамично Оптимиране (DP)?

Динамичното оптимиране е алгоритмичен подход за решаване на сложни задачи чрез разбиването им на по-малки, застъпващи се подзадачи. Ключовата идея е да не се преизчислява нищо, което вече е било сметнато веднъж.

Златна мисъл: "Тези, които не помнят миналото, са обречени да го повтарят." – Запаметяваме отговорите в масив/речник, за да свалим сложността от експоненциална до линейна.

1. Застъпващи се подзадачи

Когато рекурсивното разбиване на задачата води до извикване на едни и същи подзадачи с еднакви параметри отново и отново.

2. Оптимална подструктура

Когато оптималното решение на глобалната задача може да бъде изведено директно от оптималните решения на нейните подзадачи.

⚖️ Двата подхода в Динамичното Оптимиране

Има два фундаментални начина за изграждане на таблицата с данни:

А. Мемоизация (Top-Down / Отгоре-надолу)

  • Започва се от крайната (голямата) задача.
  • Използва се стандартна рекурсия.
  • Преди всяко изчисление се проверява дали резултатът вече не е записван в паметта.

Б. Табулация (Bottom-Up / Отдолу-нагоре)

  • Започва се от най-малките базови случаи (основата).
  • Използва се итерация (цикли), без рекурсивни извиквания.
  • Таблицата (обикновено масив) се попълва последователно стъпка по стъпка.
  • По-ефективен подход в практиката, тъй като спестява заделяне на памет в системния стек.

Сравнение на неефективна рекурсия срещу оптимизиран Bottom-Up подход.

Традиционен (Бавен) подход: O(2^n)

long SlowFib(int n) {

    if (n <= 1) return n;

    return SlowFib(n - 1) + SlowFib(n - 2); // Ужасно много повторения!

}

Оптимизиран ДО подход (Табулация): O(n)

long GetFibonacci(int n) {

    if (n <= 1) return n;


    // Заделяне на "склад" за отговорите

    long[] fib = new long[n + 1];

    fib[0] = 0;

    fib[1] = 1;


    // Попълване стъпка по стъпка нагоре

    for (int i = 2; i <= n; i++) {

        fib[i] = fib[i - 1] + fib[i - 2];

    }


    return fib[n];

}

📝 Класически задачи за Изпит (Кликни за решение)

Тези концепции са ядрото на изпитите по АСД. Натиснете върху задачата, за да видите логиката и кода.

Задача 1: Минимален брой монети за ресто (Coin Change) Честа

Условие: Дадени са видове монети (напр. 1, 3, 4) и целева сума. Намерете минималния брой монети, необходими за получаване на сумата.


C# Имплементация:

int MinCoins(int[] coins, int target) {

    int[] dp = new int[target + 1];

    Array.Fill(dp, target + 1); // Запълваме с "безкрайност"

    dp[0] = 0; // За сума 0 ни трябват 0 монети


    for (int i = 1; i <= target; i++) {

        for (int j = 0; j < coins.Length; j++) {

            if (coins[j] <= i) {

                dp[i] = Math.Min(dp[i], dp[i - coins[j]] + 1);

            }

        }

    }

    return dp[target] > target ? -1 : dp[target];

}
Задача 2: Задача за раницата (0-1 Knapsack Problem) Класика

Условие: Имате предмети с определени тегла и стойности. Трябва да изберете комбинация от предмети, чието общо тегло не надвишава капацитета на раницата, така че общата им стойност да е максимална.


Идея за матрица dp[i, w]: Пази максималната стойност, която може да се събере с първите i предмета при капацитет w.
