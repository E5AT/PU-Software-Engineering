Ден 8: Графи, DFS и BFS

Докато дърветата имат строга йерархия "родител-дете", графите позволяват връзка от всеки към всеки. Те са идеални за моделиране на социални мрежи, пътни карти, компютърни мрежи и зависимости.

🎯 Фокус за изпита (Теми 12 и 13): Професорите винаги питат за свойствата на Матрицата на съседство (напр. кога е симетрична). Също така трябва да можеш без грешка да разпишеш кодовете за DFS (чрез рекурсия/стек) и BFS (чрез опашка).

Какво покриваме днес:

  • Тема 12: Графи. Матрица на съседство и нейните математически свойства.
  • Тема 13: Обхождане в дълбочина (Depth-First Search - DFS).
  • Тема 13: Обхождане в ширина (Breadth-First Search - BFS) чрез Опашка.
Тема 12 от Конспекта

Матрица на съседство

Графът се състои от върхове (Vertices - V) и ребра (Edges - E). Един от най-лесните начини да представим граф в програмирането е чрез двумерен масив (Матрица на съседство) с размери N x N (където N е броят на върховете).

Правило за запис:
Ако има ребро от връх i до връх j, тогава matrix[i, j] = 1 (или теглото на реброто).
Ако няма връзка, matrix[i, j] = 0.

Ключови свойства за изпита:

  • Неориентиран граф: Матрицата е перфектно симетрична спрямо главния диагонал (т.е. matrix[i, j] == matrix[j, i]). Ако град А е свързан с град Б, то и Б е свързан с А.
  • Ориентиран граф: Матрицата не е задължително симетрична (еднопосочни улици).
  • Главен диагонал: Ако няма примки (ребро от връх към самия него), всички елементи по главния диагонал matrix[i, i] са 0.

Инициализация в C#

int n = 5; // Брой върхове
int[,] matrix = new int[n, n];

// Добавяне на неориентирано ребро между връх 0 и връх 2
matrix[0, 2] = 1;
matrix[2, 0] = 1;
Тема 13 от Конспекта

Обхождане в дълбочина (DFS)

Depth-First Search (DFS): Избираме начален връх, маркираме го като посетен и веднага се спускаме колкото се може по-надълбоко по първото му възможно непосетено ребро. Когато стигнем задънена улица, се връщаме стъпка назад (разчитайки на рекурсията).

C# Реализация (Рекурсивен подход)

Нуждаем се от глобален масив visited, за да не зациклим безкрайно в графа! 

static int[,] matrix;        // Матрицата на съседство
static bool[] visited;       // Масив за маркиране на посетените върхове
static int n;                // Брой върхове

static void DFS(int v)
{
    // 1. Маркираме текущия връх като посетен и го отпечатваме
    visited[v] = true;
    Console.Write(v + " ");

    // 2. Проверяваме всички възможни съседи чрез матрицата
    for (int i = 0; i < n; i++)
    {
        // Ако има ребро от v до i (== 1) И върхът i НЕ е посетен
        if (matrix[v, i] == 1 && !visited[i])
        {
            DFS(i); // Гмуркаме се дълбоко в него
        }
    }
}
Сложност: При използване на матрица на съседство, сложността е O(V²), където V са върховете. Това е така, защото за всеки от V-те върха, ние извъртаме цикъл от 0 до N, за да проверим целия му ред в матрицата.
Тема 13 от Конспекта

Обхождане в ширина (BFS)

Breadth-First Search (BFS): Обхожда графа на нива (вълни). Първо посещава всички преки съседи на началния връх. Едва след това преминава към съседите на съседите. Задължително използва ОПАШКА (Queue) за пазене на поредността.

C# Реализация

static void BFS(int startNode)
{
    Queue<int> q = new Queue<int>();

    // 1. Добавяме стартовия връх и го маркираме
    q.Enqueue(startNode);
    visited[startNode] = true;

    // 2. Въртим цикъла докато опашката не се изпразни
    while (q.Count > 0)
    {
        int curr = q.Dequeue(); // Взимаме първия влязъл
        Console.Write(curr + " ");

        // 3. Добавяме всичките му непосетени съседи в опашката
        for (int i = 0; i < n; i++)
        {
            if (matrix[curr, i] == 1 && !visited[i])
            {
                visited[i] = true; // Маркираме ВЕДНАГА при влизане в опашката
                q.Enqueue(i);
            }
        }
    }
}
Използване: BFS е най-добрият алгоритъм за намиране на най-кратък път (минимален брой ребра) в нетегловен граф. За разлика от него, DFS е по-добър за изследване на всички възможни пътища (Backtracking) или търсене на цикли.
Проверка на знанията

Интерактивна тренировка

ВЪПРОС 1 — ИЗБОР НА АЛГОРИТЪМ
Искате да напишете функция, която намира колко приятели трябва да "прескочите", за да стигнете от Иван до Мария в социална мрежа (напр. Иван познава Пешо, а Пешо познава Мария = 2 стъпки). Кой алгоритъм ще изберете?
👆 Кликни за отговор
Задължително BFS (Обхождане в ширина).

BFS обхожда графа на вълни – първо проверява всички на 1 стъпка разстояние, после всички на 2 стъпки и т.н. Това гарантира, че първият път, когато срещнем Мария, сме я намерили по най-краткия възможен маршрут. DFS може да тръгне по напълно грешен клон на мрежата и да направи стотици стъпки.
ВЪПРОС 2 — СИМЕТРИЯ В МАТРИЦАТА
Нека матрицата на съседство M представя граф с 5 върха. Забелязвате, че M[2, 4] = 1, но M[4, 2] = 0. Какво означава това за самия граф?
👆 Кликни за отговор
Означава, че графът е ориентиран (Directed Graph).

Има еднопосочно ребро (стрелка) от връх 2 към връх 4, но няма връзка наобратно от 4 към 2. Ако графът беше неориентиран, матрицата трябваше да е симетрична спрямо главния диагонал и M[4, 2] също трябваше да е 1.
ВЪПРОС 3 — СТРУКТУРИ ОТ ДАННИ ЗА ОБХОЖДАНЕ
Въпрос за бърз блиц-тест: Какви вътрешни структури от данни (от разгледаните в Ден 2) използват съответно DFS и BFS под капака си, за да пазят реда на обхождане?
👆 Кликни за отговор
- DFS: Използва Стек (LIFO). Най-често не се пише ръчно стек, а се разчита на системния стек чрез рекурсия (както е в кода по-горе).
- BFS: Използва Опашка (FIFO). Редът на изчакване се управлява чрез експлицитен обект Queue<int>.
