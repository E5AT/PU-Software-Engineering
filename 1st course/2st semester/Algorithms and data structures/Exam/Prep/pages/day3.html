Тема 2 от Конспекта

Сравнение на Рекурсия и Итерация

Рекурсия е подход, при който един метод извиква сам себе си, докато стигне до дъно (базов случай). Итерация е използването на цикли (for, while) за повтаряне на блок от код.

Характеристика Рекурсия Итерация (Цикли)
Памет Консумира повече ресурси, защото всяко извикване заделя нова рамка (Stack Frame) в системния стек. Много по-ефективна. Работи в рамките на една единствена стек рамка.
Четимост Води до елегантни и кратки решения (особено при обхождане на дървета/графи). Може да стане сложна и дълга за специфични математически проблеми.
Грешки Ако няма правилно "дъно" или извикванията са твърде много, се стига до StackOverflowException. Опасност от безкрайни цикли (забиване), но не препълва паметта по същия начин.

Пример: Факториел (n!)

И при двата варианта (рекурсия и цикъл) сложността е O(n), но според проф. Голев за линейни процеси като този винаги трябва да се предпочита итерацията.

// Рекурсивен подход (заема O(n) памет в стека)
long Factorial(int n) 
{
    if (n <= 1) return 1; // Дъно
    return n * Factorial(n - 1);
}
Оценка на сложността

Числа на Фибоначи: Клопката на Рекурсията

Редицата на Фибоначи се дефинира като: f(n) = f(n-1) + f(n-2). На пръв поглед рекурсията изглежда идеална.

🚨 Внимание: Проф. Голев изрично подчертава, че директната рекурсия тук е изключително неефективна. Едни и същи числа се пресмятат многократно (т.нар. "дърво на извикванията" расте експлозивно). Сложността е експоненциална: O(2ⁿ).

Лошият (Рекурсивен) Подход: O(2ⁿ) време

long FibRecursive(int n) 
{
    if (n == 0 || n == 1) return n;
    return FibRecursive(n - 1) + FibRecursive(n - 2); // Огромно дублиране на работа
}

Добрият (Итеративен) Подход: O(n) време

С един прост цикъл, изчисляването на Фибоначи става линейно и изключително бързо!

long FibIterative(int n) 
{
    if (n == 0 || n == 1) return n;
    
    long prev = 0, curr = 1, next = 0;
    for (int i = 2; i <= n; i++) 
    {
        next = prev + curr;
        prev = curr;
        curr = next;
    }
    return curr;
}
Класически алгоритъм (по Наков)

Ханойски кули

Преместването на n диска от Стълб 1 на Стълб 2, като използваме Стълб 3 за помощ и спазваме правилото "голям диск никога не се слага върху малък". Това е задача, която на практика няма как да се реши лесно без рекурсия.

Логика на алгоритъма:

  1. Премести горните n-1 диска от началния към помощния стълб.
  2. Премести най-долния (най-голям) диск от началния към крайния стълб.
  3. Премести онези n-1 диска от помощния към крайния стълб.

C# Реализация

void SolveHanoi(int n, char start, char end, char temp) 
{
    if (n == 1) 
    {
        Console.WriteLine($"Премести диск 1 от {start} на {end}");
        return;
    }
    
    // 1. Местим n-1 диска на помощния
    SolveHanoi(n - 1, start, temp, end); 
    
    // 2. Местим най-големия
    Console.WriteLine($"Премести диск {n} от {start} на {end}");
    
    // 3. Местим n-1 диска от помощния към крайния
    SolveHanoi(n - 1, temp, end, start); 
}
Времева сложност: Броят на ходовете се описва с формулата T(n) = 2ⁿ - 1. Сложността е експоненциална O(2ⁿ). Добавянето на само 1 нов диск удвоява времето за решаване!
Проверка на знанията

Интерактивна тренировка

Реши тези въпроси наум, за да затвърдиш разликата между O(n) и O(2ⁿ).

ВЪПРОС 1 — STACK OVERFLOW
Защо рекурсивните функции са предразположени към хвърляне на StackOverflowException, докато while(true) (безкраен цикъл) обикновено просто "забива" програмата, но не хвърля такава грешка?
👆 Кликни за отговор
При всяко рекурсивно извикване операционната система заделя нов блок памет (Stack Frame) за локалните променливи и адреса на връщане. Тъй като паметта на стека е малка и ограничена (обикновено 1-2 MB), твърде много извиквания бързо я изчерпват.

От друга страна, един безкраен цикъл преизползва една и съща стек рамка отново и отново, така че памет не се губи – просто процесорът се товари.
ВЪПРОС 2 — ВРЕМЕВА СЛОЖНОСТ
Спрямо конспекта, каква е времевата сложност (Big-O) на итеративния подход за пресмятане на n-тото число на Фибоначи спрямо директния рекурсивен?
👆 Кликни за отговор
Итеративен (с for цикъл): Линейна сложност O(n). Всяко число от 1 до n се пресмята точно веднъж.

Директен рекурсивен: Експоненциална сложност O(2ⁿ) (по-точно O(1.618ⁿ)). Прави се огромно количество дублирани изчисления.
ВЪПРОС 3 — ХАНОЙСКИ КУЛИ (ИЗЧИСЛЕНИЕ)
Ако имаш 3 диска на Ханойските кули, колко минимални хода (премествания) са нужни, за да се реши задачата? А при 4 диска?
👆 Кликни за отговор
Формулата за броя на ходовете е 2ⁿ - 1.

За 3 диска: 2³ - 1 = 8 - 1 = 7 хода.
За 4 диска: 2⁴ - 1 = 16 - 1 = 15 хода.
