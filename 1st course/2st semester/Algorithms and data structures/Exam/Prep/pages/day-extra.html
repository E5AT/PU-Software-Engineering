Реални Имплементации на Структури от Данни

Много правилна забележка! Когато говорим за "реализация в .NET" на академично ниво (особено на изпит), често се има предвид не просто да извикаш new List<int>(), а да покажеш, че разбираш как този List е написан отвътре, използвайки най-базовите типове (масиви и референции).

🎯 Защо е важно: Тук са събрани кодовете от материалите на твоя асистент. Прегледал съм ги, добавил съм подробни обяснителни коментари към логиката им и леко съм форматирал/съкратил излишния код, за да се четат и разбират по-лесно.

Тези имплементации ти показват "кухнята" на C#:

  • Как един масив се разширява (Resize), когато се напълни.
  • Как възлите (Nodes) се свързват чрез указатели (референции).
  • Как работи събирането на боклука (Garbage Collector), когато откачим възел (напр. node.next = null).
Динамичен масив

Custom ArrayList (Списък чрез Масив)

Това е начинът, по който работи вграденият List<T> в C#. Той пази данните в обикновен масив с фиксиран размер. Когато масивът се напълни, се създава нов, двойно по-голям масив, и старите елементи се копират в него.

public class CustomArrayList
{
    private object[] arr;
    private static readonly int INITIAL_CAPACITY = 4;
    private int count; // Реалният брой добавени елементи

    public int Count => count;

    public CustomArrayList()
    {
        arr = new object[INITIAL_CAPACITY];
        count = 0;
    }

    // Добавяне на елемент в края е просто вмъкване на позиция 'count'
    public void Add(object item)
    {
        Insert(count, item);
    }

    // Сърцето на динамичния масив: Вмъкване с евентуално преоразмеряване
    public void Insert(int index, object item)
    {
        if (index > count || index < 0)
            throw new IndexOutOfRangeException("Invalid index");

        object[] extendedArray = arr;

        // АКО масивът е пълен, създаваме нов с ДВОЕН размер
        if (arr.Length == count + 1)
        {
            extendedArray = new object[arr.Length * 2];
        }

        // 1. Копираме елементите ПРЕДИ индекса
        Array.Copy(arr, extendedArray, index);
        count++;
        
        // 2. Изместваме елементите СЛЕД индекса с 1 позиция надясно
        Array.Copy(arr, index, extendedArray, index + 1, count - index - 1);
        
        // 3. Поставяме новия елемент на освободеното място
        extendedArray[index] = item;
        
        // 4. Подменяме стария масив с новия (старият ще се изчисти от Garbage Collector-а)
        arr = extendedArray;
    }

    // Изтриване по индекс
    public object Remove(int index)
    {
        if (index >= count || index < 0)
            throw new IndexOutOfRangeException("Invalid index");

        object item = arr[index];

        // Изместваме всички елементи след изтрития с 1 позиция наляво, за да запълним дупката
        Array.Copy(arr, index + 1, arr, index, count - index - 1);
        
        // Зануляваме последната позиция, за да не "държим" излишен обект в паметта
        arr[count - 1] = null;
        count--;

        return item;
    }
}
Свързани Възли

Custom LinkedList (Свързан Списък)

За разлика от масива, свързаният списък не пази елементите си един до друг в паметта. Вместо това, всеки елемент е опакован в обект Node (Възел), който пази стойността си и указател (референция) към следващия възел.

// Помощен клас за възел (Node)
public class LinkedListNode<T>
{
    public T Element { get; set; }
    public LinkedListNode<T> Next { get; set; } // Връзката към следващия!

    public LinkedListNode(T element)
    {
        this.Element = element;
        this.Next = null;
    }

    // Конструктор, който автоматично се "закача" след даден предишен възел
    public LinkedListNode(T element, LinkedListNode<T> prevNode)
    {
        this.Element = element;
        this.Next = prevNode.Next;
        prevNode.Next = this;
    }
}

public class LinkedList<T>
{
    private LinkedListNode<T> head; // Начало на списъка
    private LinkedListNode<T> tail; // Край на списъка (оптимизация за бързо добавяне)
    public int Count { get; private set; }

    public void Add(T item)
    {
        if (head == null)
        {
            // Ако е празно, новият възел е едновременно и глава, и опашка
            LinkedListNode<T> newNode = new LinkedListNode<T>(item);
            head = tail = newNode;
        }
        else
        {
            // Закачаме го след текущата опашка и го обявяваме за нова опашка
            LinkedListNode<T> newNode = new LinkedListNode<T>(item, tail);
            tail = newNode;
        }
        Count++;
    }

    // Изтриване по индекс е бавно O(n), защото трябва да го намерим, прескачайки възлите
    public T RemoveAt(int index)
    {
        LinkedListNode<T> current = head;
        LinkedListNode<T> previous = null;
        int i = 0;

        while(current != null)
        {
            if (index == i)
            {
                // Откачаме възела, като караме предишния да сочи към следващия (прескачаме current)
                if (previous != null)
                    previous.Next = current.Next;
                else
                    head = current.Next; // Ако трием главата
                    
                Count--;
                return current.Element;
            }

            i++;
            previous = current;
            current = current.Next; // Преминаваме на следващия
        }
        return default(T);
    }
}
LIFO: Last In, First Out

Стек (Реализации с Масив и Списък)

Стекът може да се реализира по два начина: чрез скрит масив (бързо, но изисква преоразмеряване) или чрез свързан списък (гъвкаво, но с повече памет за възли). И двата подхода целят едно - операциите Push и Pop да са O(1).

1. Стек чрез Масив (ArrayStack)

public class ArrayStack<T>
{
    private T[] elements;
    public int Count { get; private set; }
    public T Peek => Count > 0 ? elements[Count - 1] : default;

    public ArrayStack(int capacity = 4)
    {
        elements = new T[capacity];
    }

    public void Push(T element)
    {
        // Ако се препълни, удвояваме масива (вграден метод)
        if (Count == elements.Length)
            Array.Resize(ref elements, Count * 2);

        elements[Count] = element;
        Count++;
    }

    public T Pop()
    {
        if (Count == 0) throw new InvalidOperationException();
        
        Count--;
        return elements[Count]; // Не го трием физически, просто намаляваме Count
    }
}

2. Стек чрез Свързан Списък (LinkedStack)

Тук винаги добавяме и премахваме от Началото (Главата) на списъка. Така операцията е светкавична O(1).

public class StackNode<T>
{
    public T Value { get; set; }
    public StackNode<T> NextNode { get; set; }

    public StackNode(T value, StackNode<T> nextNode = null)
    {
        this.Value = value;
        this.NextNode = nextNode;
    }
}

public class LinkedStack<T>
{
    public int Count { get; private set; }
    public StackNode<T> PeekNode { get; private set; } // Това е "Главата"

    public void Push(T element)
    {
        // Създаваме нов възел, който сочи към досегашния връх. Новият става връх.
        PeekNode = new StackNode<T>(element, PeekNode);
        Count++;
    }

    public T Pop()
    {
        if (Count == 0) throw new InvalidOperationException();
        
        var removedValue = PeekNode.Value;
        // "Обезглавяваме" стека - вторият елемент става нов връх
        PeekNode = PeekNode.NextNode; 
        Count--;

        return removedValue;
    }
}
FIFO: First In, First Out

Опашка чрез Свързан Списък (LinkedQueue)

При опашката добавяме в Края (Tail) и вадим от Началото (Head). За да е бързо (O(1)), пазим референции и към двете.

// Възел за опашка (тук е направен двойно свързан, макар че за опашка стига и единичен)
public class QueueNode<T>
{
    public T Value { get; private set; }
    public QueueNode<T> NextNode { get; set; }

    public QueueNode(T value)
    {
        this.Value = value;
    }
}

public class LinkedQueue<T>
{
    public int Count { get; private set; }
    public QueueNode<T> Head { get; private set;}
    private QueueNode<T> Tail;

    // Добавяме на опашката (Tail)
    public void Enqueue(T element)
    {
        var node = new QueueNode<T>(element);
        
        if (Count == 0)
        {
            Head = Tail = node;
        }
        else
        {
            // Закачаме новия възел след текущия Tail и местим Tail върху него
            Tail.NextNode = node;
            Tail = node;
        }
        Count++;
    }

    // Вадим от главата (Head)
    public T Dequeue()
    {
        if (Count == 0) throw new InvalidOperationException();
        
        var removedElement = Head.Value;
        // Преместваме главата към следващия елемент. Старата глава ще се събере от GC.
        Head = Head.NextNode; 
        Count--;
        
        if (Count == 0) Tail = null; // Почистване, ако опашката остане празна
        
        return removedElement;
    }
}
N-ary Tree

Общо Дърво (Произволен брой деца)

Това е дърво, в което всеки възел може да има произволен брой наследници (а не само 2). Затова децата се пазят в списък (List).

public class TreeNode<T>
{
    public T Value { get; set; }
    private List<TreeNode<T>> children; // Списък с децата

    public TreeNode(T value)
    {
        this.Value = value;
        this.children = new List<TreeNode<T>>();
    }

    public int ChildrenCount => children.Count;

    public void AddChild(TreeNode<T> child)
    {
        this.children.Add(child);
    }

    public TreeNode<T> GetChild(int index) => children[index];
}

public class Tree<T>
{
    public TreeNode<T> Root { get; private set; }

    public Tree(T value, params Tree<T>[] subTrees)
    {
        this.Root = new TreeNode<T>(value);
        foreach (var child in subTrees)
        {
            this.Root.AddChild(child.Root);
        }
    }

    // DFS обхождане (Итеративно) чрез изричен СТЕК
    public void DFS()
    {
        Stack<TreeNode<T>> stack = new Stack<TreeNode<T>>();
        stack.Push(this.Root);

        while(stack.Count > 0)
        {
            TreeNode<T> currentNode = stack.Pop();
            Console.Write(currentNode.Value + " ");

            // Добавяме децата в стека (отзад напред, за да се извадят в правилен ред)
            for (int i = currentNode.ChildrenCount - 1; i >= 0; i--)
            {
                stack.Push(currentNode.GetChild(i));
            }
        }
    }
}
Binary Search Tree

Двоично Дърво за Търсене

Тук типовете данни трябва да са сравними помежду си (where T : IComparable<T>), за да знаем кое е "по-малко" (отива вляво) и кое "по-голямо" (отива вдясно). Това е по-сложната имплементация, която включва родителски указатели.

public class BinaryTreeNode<T> where T : IComparable<T>
{
    public T Value;
    public BinaryTreeNode<T> Parent;
    public BinaryTreeNode<T> LeftChild;
    public BinaryTreeNode<T> RightChild;

    public BinaryTreeNode(T value)
    {
        this.Value = value;
    }
}

public class BinarySearchTree<T> where T : IComparable<T>
{
    private BinaryTreeNode<T> root;

    // Итеративно ТЪРСЕНЕ (много бързо, без рекурсия)
    public BinaryTreeNode<T> Find(T value)
    {
        BinaryTreeNode<T> node = this.root;

        while (node != null)
        {
            int cmp = value.CompareTo(node.Value);
            
            if (cmp < 0) node = node.LeftChild;        // Търсеното е по-малко -> Ляво
            else if (cmp > 0) node = node.RightChild; // Търсеното е по-голямо -> Дясно
            else break;                               // Намерено! (cmp == 0)
        }
        return node;
    }

    public void Insert(T value)
    {
        this.root = Insert(value, null, root);
    }

    // Рекурсивно ВМЪКВАНЕ
    private BinaryTreeNode<T> Insert(T value, BinaryTreeNode<T> parent, BinaryTreeNode<T> node)
    {
        if (node == null)
        {
            // Намерихме празното място! Създаваме възела и му закачаме родителя.
            node = new BinaryTreeNode<T>(value);
            node.Parent = parent;
        }
        else
        {
            int cmp = value.CompareTo(node.Value);
            if (cmp < 0)
                node.LeftChild = Insert(value, node, node.LeftChild);
            else if (cmp > 0)
                node.RightChild = Insert(value, node, node.RightChild);
        }
        return node;
    }
}
Матрица на Съседство

Граф и BFS обхождане

Реализация на граф чрез най-бързия начин - двумерен масив [,]. Стойността в матрицата показва теглото на реброто (или 0, ако няма ребро).

public class Graph
{
    private int[,] vertices; // Матрицата

    public Graph(int[,] vertices)
    {
        this.vertices = vertices;
    }

    // Връща всички върхове, към които има ребро от връх i
    public List<int> GetSuccessors(int i)
    {
        List<int> successors = new List<int>();
        for (int j = 0; j < vertices.GetLength(0); j++)
        {
            if (vertices[i, j] != 0) // Ако има ребро
            {
                successors.Add(j);
            }
        }
        return successors;
    }

    // Обхождане в Ширина (на вълни)
    public void TraverseBFS(int startNode)
    {
        bool[] visited = new bool[vertices.GetLength(0)];
        Queue<int> queue = new Queue<int>(); // Използваме вградената Опашка
        
        queue.Enqueue(startNode);
        visited[startNode] = true; // Маркираме ВЕДНАГА като го добавим в опашката

        while(queue.Count > 0)
        {
            int currentNode = queue.Dequeue();
            Console.Write(currentNode + " ");

            // Взимаме всички съседи на текущия възел
            List<int> successors = GetSuccessors(currentNode);

            foreach (int childNode in successors)
            {
                if (!visited[childNode])
                {
                    queue.Enqueue(childNode);
                    visited[childNode] = true; // Маркираме!
                }
            }
        }
    }
}
